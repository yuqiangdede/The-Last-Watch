# 固定审稿报告格式 V1.0

> 执行时复制以下模板，**所有一级章节标题、表格字段、问题小节字段保持原顺序**。可增加问题行和细节，但不可省掉某个栏目；不适用填写「不适用」，缺证据写「待核实」。**不得填写虚构分值、引用或行号**。

### 填表纪律

1. 有目录的项目写实际路径，不写捏造行号；抽取段落要贴原文。
2. 合计分数学上等于七维折算分总和。显示 1 位小数。
3. 从没读到某章，不可给它分数。审稿“建议”和“已经修改”严格分开。
4. 发现**现有旧质检报告说 PASS，但原文仍有严重问题**时，以实读正文/有效设定为准。
5. 所有模式、章节数量的一级目录相同；复审继续使用旧 ID，跨章问题可复用一个 ID 列多处证据。
