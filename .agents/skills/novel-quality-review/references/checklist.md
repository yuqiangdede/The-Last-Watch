# 审稿检查矩阵与常见误判

遵循顺序：**事实 → 因果 → 人物 → 阅读感受 → 语言**。以下是检查提醒，不是自动判错表。

## 1. 逐章事实表

每章先填写：`章号｜场景开始时间/结束时间｜人物与状态｜地点/距离｜任务｜敌我已知信息｜装备/弹药/补给/伤情｜产生的结果｜带到下一章的未解项`。跨章核对起止时间是否衔接、情报从何而来、伤势和物资是否被无理由清零。

## 2. 八类重点核查

| 类别 | 必问 | 可能的正确解释 |
|---|---|---|
| L1 剧情/政治 | 弘毅领与锐科谁与谁冲突？一方为何给另一方情报？权力层级/命令来自哪？ | 谈判、诱导、假旗、角色误读；不等于已经全面开战 |
| L2 情报/证据 | 士兵从编号、涂层、地图、设备日志，到「谁干的」「目的是什么」中间缺哪些证据？ | 是人物猜测、误导线索、非官方来源，需要保留不确定性 |
| L3 事件因果 | 若去掉某人指令/某件道具，结果还会发生吗？失败如何引发后续损失？ | 运气是允许的，但不应连续替代主角决策和代价 |
| L4 时空/战术 | 时间刻度、路程/机动速度、风雪/风级、地形、可视距离、射击条件、掩体与撤退方案是否相符？ | 有技术改进/侦察预置时应在前文有可见交代 |
| L5 装备/轻科幻 | 新武器哪里来？消耗与弹药口径兼容吗？无人机天气限制？超感有代价吗？ | 未来技术可以不同，但不能与本书技术边界自冲突 |
| L6 角色/后果 | 为什么留守、叛逃、争执、指责、独自执行高危任务？过去的伤病/关系改变行动了吗？ | 军人可以冒险，但应有军事目的、撤退条件或心理动因 |
| L7 伏笔/信息释放 | 作者知道什么、人物知道什么、读者知道什么？隐藏真相是否提前揭穿？ | 视角受限的误判可制造悬念，不应替读者下最终结论 |
| L8 网文/AI式表达 | 每章是否有状态变化、紧张与缓冲、人物独有细节？是否重复总结、堆参数、章尾模板反转？ | 短句/比喻/军人口令/低落情绪本身都不该扣分 |

## 3. 《崖边戍卒》的专有护栏

- 主体类型：战争群像型网络小说；**人物使读者留下，任务推动翻页**。不以辞藻、军备参数、每章死亡数来证明优秀。
- 第三人称有限视角为主；若出现另一人的想法，先判断是否已经切换清晰视角。
- 先检查真实角色列表与阶段编制，**不要预设五人始终同时出场**；留守必须有观察/报警/接防/撤离逻辑。
- 关注陈渡旧伤、外骨骼与补给，林霰弹药与任务定位、霍山维修能力边界，严恪/江小年随阶段入队后的岗位区分。
- 第四卷的叛逃、严恪牺牲、林霰阵亡、杜衡殉节有既定因果链；**不得因审稿偏好直接修改角色命运**。
- 林霰的“复活可能”属于作者秘密/读者悬念：不得根据设定中的真相建议正文提前宣告；审查时只核对是否出现不该出现的真实存活证据、上帝视角泄密或设定破功。
- 剧情仍在设计中的后续卷只作为「未定」，不可拿后期草案倒灌前四卷。

## 4. 去 AI 味时的正反例（示意，非引用现有正文）

坏：`这一刻，陈渡终于明白，真正的战友情，不只是并肩作战，更是永不言弃。`

问题：抽象总结替代行为、假对比、作者替角色解释。

较优：`陈渡没回话。他把备用弹匣推到老霍手边，自己拿起那把卡着泥的旧枪。`

并非要求所有场景都短句；修改后还应检查是否损失情绪和人物声口。

坏：`有敌方规格编号，所以这一定是锐科总部策划的地质毁灭计划。`

问题：设备归属≠执行人身份≠行动目的，证据链跳级。

较优方向：写成角色的假设、保留其他可能；让后续侦察/缴获情报验证，不直接替角色把悬念讲完。

## 5. 多章审稿必查

- 同一地点南北东西方向与真实描写是否一致；地图是否来自可解释的测绘/缴获/共享渠道。
- 日夜与行动时间、天气预报/可见度的数值是否跨章互相打架。
- 装备来源和去向、每次消耗是否进入后续行动约束。
- 群像角色是否各有发挥；是否连续几章只是同一类枪战或同一结构反转。
- 一个战略危机是否被过早当作已确定全面战争；作者是否在读者还没准备好时提前揭示真相。
- 前文提到的钩子/通行证/线索是否有「埋设→强化→兑现」链，而非临时空降。
- 同一个问题在前一版报告是否宣告解决却在最新版正文仍存在；**历史报告不是证据，应重新核对当前版本**。

## 6. 证据不足时的标准表述

- `已证实：第002章原文写 X，第004章原文写非 X，且两者均为叙述事实，因此冲突。`
- `高可信推断：第005章未见撤离安排，人物冒险明显偏高；仍可能是作者刻意设计的失误，需补后果。`
- `待核实：装备从何处取得尚未找到，需查前文某章/世界观文档；当前不能判定“凭空出现”。`

禁止措辞：`AI写的概率98%`、`这一定是作者漏写`（仅凭疑点）、`全面开战`（仅凭局部冲突）、`完全没有AI味`（没有阅读全文）、`已修复`（未复查正文）。
