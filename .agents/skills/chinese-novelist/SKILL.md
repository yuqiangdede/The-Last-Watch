# Chinese Novelist: 中文小说创作助手

## 三大黄金法则

1. **展示而非讲述** - 用动作和对话表现，不要直接陈述
2. **冲突驱动剧情** - 每章必须有冲突或转折
3. **悬念承上启下** - 每章结尾必须留下钩子

## 特性说明

- **双架构支持**：
  - **深度模块化架构（Deep Mode）**：面向多阵营、多人物、复杂规则的长篇史诗。采用 9 级工程目录、`AGENTS.md` 协作中枢、分级人物主档体系（主角/、配角/、辅助角色/第XX章）、分卷因果三问大纲、JIT 渐进加载与动态事实账本，彻底根治长篇设定漂移与人设崩塌。
  - **标准轻量架构（Standard Mode）**：面向 10-20 章短中篇快速创作，保持极简五大核心文件，人物档案按主角/配角/辅助角色+章节归纳。
- **三级分类小传体系与写前角色完备性拦截（Character Audit Quality Gate）**：
  - **核心铁律（全员小传与多次登场必立传）**：**主角和配角都要有人物小传，理论上只要多次出现的人物都要设立小传！**除纯一次性出现的无名龙套过客外，所有具备剧情推动作用或后续复现的角色均须建档。
  - **小传定位（性格底色与冰山原则）**：**小传没必要所有的情节都在正文中提及，只是为性格和人物建立一个基础而已**。小传是人物水面下的冰山底座，切忌在正文中生搬硬套或以说明文形式全盘倒灌，而是通过行动、抉择与台词自然流露。
  - **合规性校验（教研质检）权威输入**：小传在后续合规性校验（合规性教研 / Quality Gate）时作为**核心基准输入**，用于逐章严格对照核验角色行为逻辑、心理动机、言行口吻是否符合人设基准，严查是否触犯「禁止偏离清单」。
  - **分级归档与写前拦截**：小传按「主角（`02-人物/主角/`）」、「核心配角（`02-人物/配角/`）」、「辅助角色（`02-人物/辅助角色/第{XX}章-[角色名].md`）」严格归档。辅助角色以**首次登场章节**命名，便于后续章节秒查老面孔并快速复用。每章动笔前必须执行出场人员盘点，发现缺少小传者必须先补齐建档，方可动笔写正文。
- **多媒体资源自由扩展（人物插画与剧情音频）**：项目默认预置「人物插画」与「剧情音频」专属目录（深度模式为 `10-人物插画/`、`11-剧情音频/`；标准模式为 `人物插画/`、`剧情音频/`）。用户可完全根据个人意愿随时增加角色的肖像立绘、视觉插画，或者特定剧情的高光配音朗读、广播剧片段与氛围配乐（BGM），并在小传与正文中自由关联引用，未提供亦不影响全自动文字创作。
- **三大防跑偏工程规则**：唯一权威源（SSOT）、JIT 渐进式按需读取、写后验证与事实回写（Fact Writeback）。
- **多主角生命线 × 世界主线时间轴硬拦截（Timeline & Chronology Quality Gate）**：
  - **核心机制**：在单章写后及全书校验阶段，严格基于 `07-创作记忆/时间轴总账.json` 与任务卡执行自动化时空质检。自动核算各主角实岁（$\text{实岁} = \text{世界当前年} - \text{出生年}$，误差 $\ge 1$ 岁阻断）、主角生命周期（未出生/已阵亡/跨卷提前登场阻断）、世界主线事件时刻表（未来大事件提前成为既成事实早产剧透阻断）、自然环境反季节冲突（寒冬写盛夏蝉鸣阻断）及地理位移物理耗时，未通过严禁标记完成！
- **四维多维一致性深度审稿体系（合并自 novel-quality-review）**：
  - **核心工具**：原生集成 `scan_chapter.py`（精确 `is_han` 正文汉字与 5 类套式扫描）与 `verify_chapter_consistency.py`（七维评分、阻断硬拦截与报告生成）。
  - **拦截规则**：每章收尾前自动核验时间轴与多主角年龄/主线事件吻合度、情节因果与伤病状态继承、主角人设契合度与禁止偏离清单、正文汉字红线指标，未通过判定为 `BLOCKED`，严禁标记完成。支持一键输出标准报告至 `08-审稿/第{XX}章-质检报告.md`。
- **Nuwa 双源动态加权文风演进与三大标杆矩阵**：采用 `alchaincyf/nuwa-skill` 深度蒸馏心智模型、决策启发式、语言指纹与反模式。独创**双源动态加权文风演进机制**：文风不仅参考用户提供的外部文本/作家语料，更深度参考小说自身已定稿的正文部分；而且**小说正文越多，参考自身的权重越重**（从起步期的外部主导 85%:15%，平滑演进至成熟期的自身主导 90%:10%），动笔前双源加权注入注意力头部，写后持续沉淀黄金段落，彻底根治长篇小说中后期“文风漂移”与“机械套模板导致自身语感割裂”的顽疾！针对军旅/群像/硬核题材原生集成三大标杆：以《士兵突击》为主要参考（重人物关系变化而非军事术语）、以《我的团长我的团》为群像参考（不完美军人、苦中作乐、控台词密度杜绝全员哲学家）、以《第一序列》为节奏参考（危险与日常交替、生活幽默感、阶段情绪回报、去无代价光环）。
- **Humanizer-zh × 说人话双引擎润色**：每章完成后联动或执行 `op7418/Humanizer-zh`（清除31种AI套式/假对比/破折号堆叠）与 `MrGeDiao/shuorenhua`（保事实/消灭翻译腔/去公文词/说人话），彻底剔除机械AI感。
- **中断续写**：自动检测未完成项目，从断点继续创作。
- **自动校验**：创作完成后自动检查字数和质量，不合格自动修复。
- **并行写作**（可选）：支持子Agent并行写作，通过 `02-写作计划.json` 协调状态。

## 核心流程

进入每个阶段时，先阅读对应的流程文档以获取详细执行指令。

### 第0步：初始化与偏好加载

读取用户偏好，检测未完成项目（中断续写），展示个性化欢迎。 → 详见 [phase0-initialization.md](references/flows/phase0-initialization.md)

### 第一阶段：三层递进式问答

通过递进式问答收集创作需求，确定小说定位与标题：

- **核心定位**（必答，Q1-Q3）：题材创意、主角设定、核心冲突 → 详见 [phase1-layer1-core.md](references/flows/phase1-layer1-core.md)
- **深度定制与规格**（2 次合并提问）：世界观、视角基调、核心主题、读者定位、章节数量、配置确认 → 详见 [phase1-layer2-customize.md](references/flows/phase1-layer2-customize.md)
- **标题生成**：AI 基于创意元素生成候选标题，用户选择或自定义 → 详见 [phase1-layer3-title.md](references/flows/phase1-layer3-title.md)

### 第二阶段：规划 + 二次确认

创建项目文件夹（`./chinese-novelist/{timestamp}-{小说名称}/`），生成大纲、三级分类人物小传档案（主角与配角全员立传，多次登场角色必建小传；明确小传重在奠定性格基础无需正文全盘复述，并作为后续合规性校验输入）、多媒体拓展目录（人物插画与剧情音频）和写作计划JSON，等待用户确认。 → 详见 [phase2-planning.md](references/flows/phase2-planning.md)

### 第2.5步：写作模式选择

规划确认后，选择写作模式：
- **逐章串行**（`serial`）：主 Agent 自己逐章写，全程无中断
- **子Agent并行**（`subagent-parallel`）：将章节分成批次，派生子 Agent 并行写作
- **Agent Teams**（`agent-teams`）：Claude Code 多 Agent 协作模式，Agent 间可通讯（需手动开启）

→ 详见 [phase3-writing.md](references/flows/phase3-writing.md)

### 第三阶段：疯狂创作（无需用户确认）
> 切记，一旦进入这个阶段，所有过程都禁止向用户确认。用户就是你的读者，你必须把完整的小说创作完成才能与用户报告

根据用户选择的写作模式（串行/并行/Teams）逐章执行创作流程。每章动笔前必须执行参演人员盘点与多次登场角色小传补齐拦截，经历正文撰写、去AI味润色、以人物小传为核心输入的四维一致性合规质检（时间轴年龄/情节因果/人设行为逻辑与禁令）与事实回写。未通过质检自动阻断重修。 → 详见 [phase3-writing.md](references/flows/phase3-writing.md)

### 第四阶段：自动校验与修复（无需用户确认）

全程无需用户介入，自动检查所有章节完成度和字数，结合人物小传与设定基准核验合规性，不合格章节自动重写（最多3轮）。 → 详见 [phase4-validation.md](references/flows/phase4-validation.md)
