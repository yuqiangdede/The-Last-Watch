# 四关执行卡（每章写后必跑）

> 这是**动手时看的单页**。规则全文在 `gate-1` 到 `gate-4`，本文件只管「按什么顺序做、做完怎么算过、过不了怎么改」。
> 位置：逐章流程阶段 C1（[chapter-checklist.md](../flows/chapter-checklist.md)）。**C1 未过，禁止进入 C2 与阶段 D。**

---

## 一、60 秒机检

```bash
# 1) 四关机械合检 + 自动落盘报告（退出码 0=PASS/带警告，1=BLOCKED，2=文件错误）
python {skillBaseDir}/scripts/scan_ai_tone.py <章节文件路径> --project-dir <项目根> --auto-report --json
```

- 报告自动写入 `08-审稿/第{XX}章-去AI味四关报告.md`。
- 报告含：四关汇总表、阻断项明细（行号/原句/为什么改/怎么改）、待裁量项、机械指标、人工复核清单。
- **BLOCKED → 先按报告第二条逐条改，改完重跑，直到 `block_count == 0`。**

> 机检只是线索。脚本抓不到的东西（信息守恒、语气是否磨平、伏笔是否被改坏）全部靠下面的人工四关。

---

### PAM01 段落级语义增量人工门禁（不新增自动阻断项）

详写/润色后依据 [PAM01 独立规范](paragraph-false-meaning.md)，按自然段＋相邻短段对「具体特写 → 静态微动作 → 概念化立场说明」做**共同主信息复述、逐句增量、删句测试和合理保留反证**。重点看同一个选择是否被三次暗示而无新事实；必要军政记录、谈判停顿、情感伏笔不得误删。人工四关报告写出 PAM01 真实覆盖范围、成立候选及净收益裁决；**机器统计未执行语义分析时不得声称脚本检出了 PAM01**。正文有效问题归语言自然度一处，不重复扣分；简写/纲要不执行本项目。

---

### 人工补查：明显重复、程式化与修饰词密度（不新增关卡）

逐章检查装备/环境重复介绍、不同人物的同款肢体反应、战斗或救援镜头重复，以及副词/程度词/形容词/描述性短语密集层叠。核查“猛地、迅速、死死、狠狠、瞬间、骤然、极其、无比”等候选时先看语境是否需要；对照邻章，记录原文位置、可验证的频次/聚集情况、保留或压缩理由。在【人工四关执行记录】增补“重复/程式化/修饰词密度核验”结果。

机械 PASS 不证明本项通过；机检未覆盖的语义复读仍需人工判定。不能断言 AI 作者概率，也不能将同一问题在重复频率和 AI 式七维评分中双扣。

---

### 四关人工补检：程式化描写与修饰词密度

逐章核对无新增意义的复读、动作和情绪模板、环境套式，以及高密度副词、程度词、形容词和描述性短语。应查看相邻已定稿章节，记录原文位置、可确认的出现频率、必要性和处理方式。在【人工四关执行记录】增设“重复/程式化/修饰词密度”说明；机检 PASS 不等于本项已通过。不得机械清词、不得假称 AI 作者鉴定；与 F-/N- 重合只扣一次七维分数。

## 一点五、独立反方审稿子智能体（四关与最终放行之间必做）

在四关机械扫描及人工阅读后、正式放行和事实回写之前，必须依照 [对抗式 AI 味审稿协议](adversarial-ai-review.md) 创建独立子智能体 `ai-style-red-team-reviewer`。子智能体以“尽量证明正文有 AI 味”为审稿假说，使用既有 G1—G4、重复频率、修饰词密度与场景叙事增量机制逐处举证；主审核对反证后裁决。不得为完成指标而制造 AI 味，不能仅凭机检 PASS 跳过。无法真实派生则按协议标注降级；不得伪称完成真实子智能体交叉审查。报告必须留下攻击、反证、裁决和复审记录。

## 二、人工四关（依次过，不许跳关、不许合并）

### G1 Humanizer-zh —— 先删多出来的话

1. 通读，标出每一处「抬高」：假对比、意义拔高、宣传语、句尾抒情尾巴、AI 高频词。
2. 只改命中的句子，改成直述；**不补写更漂亮的句子**。
3. 检查改动是否把限定词删掉了（「可能」→「就是」是事故，不是润色）。

### G2 speak-human-tw —— 再清空转与腔调

1. 逐段问：这段有没有提供本章独有的信息？没有的空转句删掉。
2. 判罐头镜头（愣住/沉默/看窗外）：删掉它读者会漏信息吗？不会就删，**不许换成同族镜头**。
3. 判立场：有没有「各有各的道理」这类和稀泥？换成本章人物的实际选择。

### G3 shuorenhua —— 把流程话改回人话

1. 找「对……进行了……」「实现了……的提升」「完成了对……的」→ 还原成可拍的动作。
2. 找翻译腔五类（过长定语、「当…时」、话题壳、句首路标、「这意味着」）→ 按白名单改，**白名单外不动**。
3. 核对情态与情报边界：有没有把「也许」写成「一定」，有没有让角色知道他不该知道的事。

### G4 lieflat —— 最后压结构套式

1. 翻案腔分级处理：抽象命题（而是认知/本质/命运）必改；具体事实（而是守备队制服）保留。
2. 数破折号（>1.5/千字要看）、看冒号提示语、查序数小标题。
3. 相邻三句同构 → 打散一句；段首零主语 → 补「这」。

## 三、判定与放行

| 结果 | 条件 | 动作 |
|---|---|---|
| `PASS` | 机检无命中，人工四关无遗留 | 进入 C2 |
| `PASS_WITH_WARNINGS` | 机检仅 WARN，人工逐条裁决 | 在报告「结论」节写清保留理由，进入 C2 |
| `BLOCKED` | 任一 BLOCK 命中，或编号常规章低于项目配置的汉字下限（超过上限须人工审核；插章按配置豁免） | 回阶段 B 定向重写，**严禁回写账本** |

**WARN 的裁决必须留痕**：每条写「保留（理由）」或「已改（改成什么）」。空白通过视为未执行。

## 四、报告模板（脚本已自动生成，人工补最后一节）

脚本生成的报告已包含：四关汇总、阻断项、待裁量项、机械指标、人工复核清单。人工作业后**只在报告末尾追加**下面这段：

```markdown
## 七、人工四关执行记录（Agent 填写）

- G1 Humanizer-zh：已执行。删除抬高点 N 处（列举行号）；未改动项 M 处，理由：……
- G2 speak-human-tw：已执行。删空转句 N 处；罐头镜头保留 N 处（功能：交代时间/打断对话/关系变化）。
- G3 shuorenhua：已执行。还原名词化动作 N 处；翻译腔处理 N 处（仅限白名单五类）。
- G4 lieflat：已执行。翻案腔：抽象改 N 处、事实辨识保留 N 处；破折号删 N 处留 N 处。
- 信息守恒自检：伤病/弹药/时间/称谓/伏笔均未因润色改变。（逐项确认）
- 人物语气自检：角色A□ 角色B□ 角色C□ 其他□ —— 按当前项目小传检查台词指纹是否仍然可分。
- 复检：scan_ai_tone.py 结果 block=0，warn=N（已逐条裁决）。
- 结论：PASS / PASS_WITH_WARNINGS（保留项理由见上）
```

## 五、争议裁决（四关互相冲突时）

1. **本书铁律 > 四关**：`04-文风/禁用表达与常见问题.md` 与 `AGENTS.md` 十大铁律优先。
2. **保事实 > 去味**：G3 的信息守恒压倒 G1/G2 的「读起来更顺」。
3. **结构与信息冲突时**：保留信息，改结构（G4 最小改动）。
4. **两关给出相反改法**：取改动更小的那个；仍不确定就保留原文并在报告里标注「待作者定夺」。
5. **人物台词与叙述冲突**：台词优先服从人物（G4-09 起手式、G2-06 罐头镜头在台词内豁免），叙述优先服从本书视角纪律（G0）。

## 六、常见误杀清单（每次复检扫一眼）

- [ ] 把「不是自然滑倒的姿态，而是重重跌落后折断骨头的死相」改成直述 → **误杀**，这是验尸推断。
- [ ] 删掉「他咳了两声」→ **误杀**，这是伤病连续性证据。
- [ ] 把机械师的粗话改成书面语 → **误杀**，人物指纹被磨平。
- [ ] 为了让句子「更具体」补了一个数字或年份 → **新增事实**，必须撤回。
- [ ] 删掉独立成段的比喻、句内排比 → **误杀**，文学手段不在白名单内。
- [ ] 为凑句长参差故意拆短句 → **制造新 AI 味**。
- [ ] 把「可能」改成「一定」以让句子更硬 → **篡改判断强度**。

## 七、与其它脚本的分工

| 脚本 | 管什么 | 什么时候跑 |
|---|---|---|
| `scan_ai_tone.py` | 四关 AI 味的**机械合检** + 报告 | C1 起手，改完复检 |
| `scan_chapter.py` | 字数、5 类套式的**快速预扫** | 可并入 C1，作补充 |
| `verify_chapter_consistency.py` | 时间轴/因果/人设/字数的**四维一致性** | C2，四关过了才跑 |

三个脚本全部 PASS 后，才允许执行阶段 D 的事实回写与归档。
