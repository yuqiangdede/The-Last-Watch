# 第三阶段：概要设定、简写与详写

所有模式执行 SKILL.md 的“每章三步写作”和 [chapter-checklist.md](chapter-checklist.md)。

1. 读取计划、当前进度和任务卡，确认章节及审核状态，按需加载资料。
2. 执行清单阶段A，输出概要设定：时地、视角、人物、承接、核心事件与因果、关系推进、结尾及连续性限制。
3. 写约500字连贯简写，与概要设定一起存入任务卡或规划草稿，标注待审核，提交用户后停下等待。
4. 用户要求调整时优先小幅、局部修改，保留未被要求变更的情节与结构；修改后再次提交审核。
5. 用户明确通过本章简写后，才执行阶段B，详写4500—5000字，再执行阶段C、D的质检、事实回写和MD/TXT交付。
6. 仅在用户请求的章节范围内继续；下一章重新经过设定、简写及用户审核。

中断恢复先查审核状态，不得把沉默、超时、原有自动模式或上一章批准当作本章批准。审核前的草稿不回写为已发生事实、不标记章节完成，不执行正文篇幅质检和TXT导出。

默认串行。用户明确要求多Agent工作时，各执行者同样遵守简写审核关卡，由主Agent提交用户，不能由Agent代为批准。共享文件修改前重读，避免覆盖其他改动。
