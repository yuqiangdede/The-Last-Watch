# 旧版审稿评分卡：参考说明

> **此文件不再维护独立评分规则。** 所有正式正文质量评分以 [review-core.md](review-core.md) 第四节的七维100分、P级和最多五次正收益修改为唯一依据；AI味37项依据 [ai-style-37-checks.md](ai-style-37-checks.md) 逐条裁决，不打分、不估计作者身份。规划与简写以 [outline-review.md](outline-review.md) 为准。

## 原评分卡可继续参考的检查思路

- **剧情与事实**：任务、证据、选择与后果相互支撑；时间、伤病、装备、资源与项目世界规则自洽。
- **人物与节奏**：角色有各自利益和声口，关键决定有代价；有效的生活戏、慢戏和叙事留白不因缺乏高潮而扣分。
- **语言与悬念**：避免无作用的假对比、解释、重复、模板化修辞，保留自然口语、专业表达及真实的信息差与阶段兑现。
- **重复频率**：频次仅可用于定位候选；对同一问题只选最相关的正文质量维度归因，不叠加扣分。若需要0—5的描述性诊断，说明实际阅读范围与依据，但诊断不参与100分总分和P级。

本文件中历史的评分表、分段评语、附加诊断分、固定文风基准、通用字数红线和工具 PASS 判定均已取消独立规范效力。正文总分、AI味专项、上游一致性及项目工程交付必须分别报告，不能互相代替。
