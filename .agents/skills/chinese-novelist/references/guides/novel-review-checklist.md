# 审稿检查矩阵与核验准则（Novel Review Checklist）

> 本核验准则合并自 `novel-quality-review`。审稿严格遵循优先级：
> **时空与主线事实 → 情节因果 → 人设动机 → 节奏可读性 → 语言去 AI 味**。

---

## 1. 核心前置对账表（事实先行）

动笔审稿前，提取本章以下硬核事实要素，核对是否与全局账本一致：
- **世界主线时间节点**：当前是哪一年？哪个月？具体时段与天候节令是什么？
- **在场主角实岁与生理阶段**：出场各主角在这一年是几岁？处于什么人生阶段？
- **地理坐标与机动耗时**：主角从上一地点移动到当前位置耗费了多久？符合交通矩阵吗？
- **生理伤病与物资装备**：上一章受的伤在行动中有无阻碍？消耗的弹药与物资扣除了吗？
- **情报边界与视角**：出场人物此时到底知道什么？有没有上帝视角抢先揭秘？

---

## 2. 八类深度核查项

| 类别 | 核心必问项 | 常见误区与正确判定 |
|---|---|---|
| **L1 剧情/宏观时局** | 阵营间的局部摩擦为何发生？命令由谁签发？是否与世界主线进程一致？ | 局部试探≠全面开战；不得把未来分卷的大事件提前当既成事实写 |
| **L2 情报/证据链** | 士兵/主角如何获知敌方动向？推断是否有缴获实物/观测日志支撑？ | 角色推测必须保留不确定性，严防证据跳级直接全知断案 |
| **L3 事件因果** | 若去掉主角的某项关键决断，局势还会这样发展吗？破局付出了什么肉体/物资代价？ | 严禁无代价光环，关键战果必须付出真实代价（伤口撕裂、物资告罄） |
| **L4 时空/主线时间** | 主角当前年龄是否符合公式（世界年 - 出生年）？季节环境是否吻合？ | 冬季严禁写盛夏蝉鸣；跨地域数千里严禁瞬移；时间单调递增不倒流 |
| **L5 装备/物理机制** | 武器型号与弹药口径是否兼容？战场掩体与射击弹道符合物理规律吗？ | 严禁机械降神凭空掏出未携带武器；严禁伤情神秘消失 |
| **L6 角色小传合规** | 主角行动是否符合小传设定的底层逻辑？是否触碰了【禁止偏离清单】？ | 冰山原则：小传无需在正文中全盘复述，重点核查言行动机不违背小传 |
| **L7 伏笔与信息释放** | 未解秘密是否被上帝视角剧透？伏笔是否有埋有收？ | 严守有限视角；主角不知道的秘密严禁通过心理旁白向读者彻底捅破 |
| **L8 语言与去 AI 味** | 是否存在假对比（不仅是…更是…）、公文翻译腔、段尾空洞哲学升华？ | 剔除 AI 播音腔与大道理，说市井粗粝人话，重人物关系轻百科术语 |

---

## 3. 问题描述与证据链规范

提出任何质量与逻辑问题时，必须严格给出三要素：
1. **精确位置与原文**：标注行号与 15-60 字原文章节句子；跨章问题必须同时列出两处矛盾文本。
2. **对照依据**：指出违背了哪份设定文档（如 `时间轴总账.json`、`人物实时状态.md` 或对应人物小传）。
3. **最小修改建议**：优先给出最小成本的改动方案（改动一句话、补充一个动作、调整一处时间标注），而非推倒重写整章。
