# 阶段三：章节简写质量审核提示词（只审不改）

> **调用示例**：审核【第四卷第128章简写】；审核【第四卷第128—132章简写】；审核【某卷某插章简写】。本阶段使用 [outline-review.md](outline-review.md) 的**章节简写剧情七维100分**，不套全书/分卷章纲16维和正文七维／37项语言AI味。

## 可直接使用的提示词

请严格执行本项目 .agents/skills/chinese-novelist/SKILL.md、references/guides/outline-review.md 及项目正式配置，对【审核对象：指定章节简写或连续简写】做**完整、独立、以剧情为核心**的审核。只审不改简写源文件；如发现实质问题，给出可以直接修改的剧情方案及可能影响，不暗中改正文或已发生事实。

### 一、真实读取及逐章核对

1. 核实目标卷章/插章、当前文件及版本，读取对应**全书大纲、目标卷纲、目标章纲、章节任务卡、实际简写**，按需查看邻章简写/已定稿正文、角色小传、世界规则、时间线、队伍或物资状态及伏笔记录。不能读取的标缺失/待核实，不虚称已完成前置核验。
2. 连续章必须**逐章逐关键事件**审核，不能抽样；单章简写要结合上下章与本卷目标。简写尚未写成完整场景描述时，区分“剧情因果必需但缺失”和“适合详写再补充的细节”。
3. 新审核不沿用历史审核分数；历史问题清单可以作为待核线索，必须重新找本轮证据。确认是作者已经锁定的结果、尚待发生的计划还是待验证设想。
4. 比对项目约定的简写目标字数/完整性，只记录工程阶段就绪度，**不得把不足正文篇幅、没有对白、文采或场景动作描写算成文学质量缺陷**。

### 一点五、章纲→简写一致性硬门禁（先于评分放行）

按照 [stage-consistency-gate.md](stage-consistency-gate.md) 逐篇把**本篇有效章纲**的必写事件、关键选择、冲突、场景职责、时序、结果与代价、核心伏笔及卷首钩子安排映射到简写的具体位置；记录上下游证据与最强反证。合理细化场景与人物互动不算不一致；无授权替换主事件、改人物决定、删去必写后果、跨章移位或提前揭谜等属实质冲突。**任一确证实质偏离即该篇简写打回，不得进入正文，哪怕七维超过80分；多章中任一篇打回，不能称整卷全通过。**上游缺失/停用/未确认须标待核实、暂缓验收；作者确认修改规划后同步有效章纲并复审，不得靠修改分数或冒称“已在简写完善”过关。

### 二、剧情七维100分（依 outline-review.md 唯一口径）

逐项0—10评分并按权重折算，给具体剧情依据：**剧情因果与冲突推进20；钩子、悬念与读者追更动力20；人物动机、选择与弧线15；世界观、势力与规则自洽15；节奏、信息释放与场景必要性15；情节原创性及反套路／反AI化10；长线伏笔与跨章连续性5**。合计100；评分不足的维度标“待核实/证据不足”，未能完整评分则说明总分不完整，不补造数字。按已提供简写层级核验，不以正文修辞/对白原句评分。

**逐篇80分评分门禁（强制）**：本项目每篇编号章、独立插章的阶段三七维折算分必须≥80，且必须另行通过相邻上游一致性、P0/P1及版本验收，才能记为“通过”并开放该篇正文；**79.9分也不通过**。全卷平均80不能覆盖低分篇；得分低于80的篇目须逐篇登记“不通过”并给出证据支持的最小修法，已获本轮修订授权时改后重新逐篇评分和比对，禁止原稿分数直接挪用。

### 三、七项剧情重点

1. **真实因果**：逐场梳理起因→角色知道什么→目标和动机→可用条件→具体行动→阻碍→结果→代价；不能因一句“随后成功”就默认合理，尤其注意关键转折的来源。
2. **人物主动性**：是否基于身份、能力、性格和信息边界作出选择；是否为推动剧情强迫人物降智、突然全知、无条件配合；群像应有自己的利益与代价。
3. **章节贡献**：与本卷章纲相比，本章是否新增事件、信息、关系、风险、情绪、决定或伏笔，避免把上一章换个场景重复一次；日常或慢戏可因关系变化、处境体感或余波成立。
4. **节奏与追读**：本章起手问题、中间转折、结果/情绪回报、收尾期待是否成链；允许非悬崖式结尾，不强加每章反转。
5. **时空和世界规则**：核人物位置、时间先后、伤病与体力、装备/资源、角色知情、能力代价、阵营利益和现实常识；简写已有明确温度、耗时、重量、距离、物态等参数时核实可行性。
6. **伏笔和跨章衔接**：引出的悬念是否已有合理回报方向；前章后果是否承接；简写中宣称的事不能和已定稿正文相矛盾。
7. **情节模式化专项**：参照 outline-review.md 的 PLOT01—07，检查假冲突、全知决策、教学式困难、情绪和解流水线、设定播报、功能性人物、所有问题过于整齐闭环；逐处提供真实阅读损害和反证。**不扫描语言37项，不用正文翻译腔、词频及AI味打分**。独立输出既有“情节模板化显著度0—5”（有证据才给），该值不是AI作者概率、也不加进100分。

### 四、反方审阅、修法及判定

- 独立反方审查主要攻击“关键选择不成立、套路化、缺少真实代价、回报不足”；真实可委派才称独立Agent，否则标注“单模型隔离式反证”。
- P0—P3问题清单必须包含目标章/关键情节定位、简写现状、证据、读者影响、最小修改的具体事件方案、可能破坏的已定事实与后续连锁影响，以及反方裁决。高价值改法优先，不靠凑数量。
- 明确**可直接进入正文／补少量简写后进入／需重修简写／资料不足待核**；与评分、结构性严重问题、项目阶段完成状态分别说明。已有实质P0/P1不能仅因分数高而报通过。

### 五、最终报告

输出：①范围、真实读取版本/资料缺失；②**章纲与简写的逐项情节映射、一致性通过/打回/待核及反证（不可被分数抵消）**；③剧情七维评分和初审结论；③逐章“目标—障碍—选择—结果—代价—承接—钩子”表及对章纲一致性；④结构套路化证据；⑤世界事实和邻章对照；⑥反方审阅方式与争议裁决；⑦P0—P3问题台账和不超过10条高价值实操改法；⑧值得保留的设计；⑨是否建议进入正文及需要作者裁决的问题；⑩实际报告保存状态。

**执行约束**：默认只读，不以简写字数或文采打正文分，不制造复杂设定来填漏洞，不为了爽点破坏角色；用户另行明确授权正收益修订时才修改简写并复审、同步相关规划索引。没有实际运行的工具、保存或核验不得写成完成。请直接执行。
