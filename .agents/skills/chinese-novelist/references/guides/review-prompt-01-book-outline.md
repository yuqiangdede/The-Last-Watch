# 阶段一：全书大纲质量审核提示词（只审不改）

> **调用示例**：审核全书大纲。将【审核对象】替换为作品实际权威全书主线／总纲文件或作者提供的文本。此文档是可直接复制的执行提示词；正式评分细则以 [outline-review.md](outline-review.md) 的“全书大纲/分卷章纲16维”部分为准，不能自建额外门禁。

## 可直接使用的提示词

请严格执行本项目 .agents/skills/chinese-novelist/SKILL.md、其 references/guides/outline-review.md 及项目正式配置，对【审核对象：全书大纲】开展**完整、独立、只读**的全书剧情质量审核，输出有来源依据的审核报告。**不得直接修改全书大纲、正文或其他作品源文件**；新增剧情只作为有明确标签的修改建议，不得当作已有设定。

**目标读者体验第一**：判断故事是否通俗易懂、剧情精彩、钩子够强、阅读轻松、逻辑合理，是否具备长篇持续追读能力。不能以文学深度代替好看；允许题材成立的想象力、爽点和类型惯例，尊重已确定的世界规则与作品定位；不能因为严谨而强加解释负担，也不能为制造反转使人物降智。

### 一、范围与证据

1. 先读取项目 AGENTS.md、novel.project.json、正式全书总纲／主线、已确认世界观和人物主档、分卷规划、结局约束、必要的已定稿正文事实及伏笔账本；按项目实际路径定位，不假定所有文件必然存在。登记文件、版本、实际通读范围和缺项。
2. 覆盖**现有全书大纲中的全部阶段／全部卷级规划**；已规划卷逐卷看因果与衔接，尚未规划的卷标明“未展开”，不靠猜测补剧情。只写到全书概要时，只在概要粒度审核。
3. 独立判断，不看、不沿用历史审核分数；旧问题台账可当作待核实线索，但需在本轮用现有剧情重新举证。
4. 分清**已发生正文事实、正式确认设定、未写规划、作者保留的开放悬念和审稿者假设**。冲突应追溯来源；不可用修改建议覆盖锁定的人物命运与结局。

### 一点五、上游权威事实一致性（审核硬门禁）

阶段一虽无更早的大纲，仍须依据 [stage-consistency-gate.md](stage-consistency-gate.md)，逐项对照作者已经确认的核心主线/终局、人物命运、世界规则与已发生事实；对照“原有锁定事项→全书大纲落实位置→一致性裁决与反证”。**确证违背锁定事实即打回本阶段审核，不得以16维高分抵消；约束资料不足则暂缓一致性验收**。合理展开不算冲突，未经授权不得用拟议新结局替换已定结局。评分与是否放行分别报告。

### 二、16维、100分量表

每项先给0—10分，再按“原分×权重÷10”折算。**16项权重依次为**：通俗易懂8、情节跌宕8、钩子与追读欲10、阅读低负担8、设定合理性6、题材特色与知识价值5、情节因果逻辑10、主角魅力与主动性7、爽点与成就感9、冲突与对抗6、新鲜感与想象力6、人物关系与情感4、节奏与结构4、悬念与伏笔兑现4、前后一致性3、作品辨识度2；合计100。逐项填写**维度、权重、原始分、折算分、具体证据、扣分理由**，不以同一个根因重复扣分。

评分锚点：9—10优秀，7—8良好，5—6一般，3—4较差，0—2严重不足。未能从现有资料验证的维度标“证据不足／不适用”，不猜数字；如果有无法评分项，不能宣称已有精确的完整100分总分，应报告已评分部分及暂缺权重。

### 三、重点专项

1. **开篇前3章／前10章**：有章级材料才实际审核开篇钩子、主角处境、首轮冲突、背景信息压力和弃书风险；没有则标“资料不足，不能逐章核验”，只审全书大纲中已写出的开篇设计。
2. **长线追读节奏**：全书各阶段是否有新问题、新阻碍、阶段胜利或情绪回报，卷间是否重复同款任务，是否存在长时间只有铺垫、后期主线变弱、收尾失控或主线断档。
3. **主角及群像**：主角有无主动选择、清晰目标、独特能力及真实代价；配角/对手是否有自己的利益、行动和局限；不机械要求打脸、战斗或爽文式胜利，按题材检验读者满足感。
4. **关键因果链**：逐个检查现有大纲中的重大转折：起因→动机→条件→行动→阻碍→结果→代价。查降智、巧合解围、临时设定救场、失效的既有解法、强行反转和无代价胜利。
5. **世界观／题材**：按实际题材核对技术与社会、力量和资源、现实常识与地理时间、专业规则等，不预设军事、仙侠、悬疑等所有题材同时适用；检查特色是否转化为剧情体验。
6. **终局与伏笔**：开端、中段、高潮与结局是否形成可理解的长期因果；设定与结局约束有无相互破坏；哪些伏笔有明确兑现路径，哪些开放问题属于有意延迟而非漏洞。
7. **剧情结构模式化**：参照 outline-review.md 的 PLOT01—07，看假冲突、全知角色、固定情绪和解、功能人物、全部问题整齐闭环等；只记录真实阅读损害，不做正文37项语言AI味检测。

### 四、审核动作与问题等级

完整阅读→建立全书因果／人物／阶段矩阵→模拟目标读者追读→16维评分→逐卷／逐阶段分析→开篇专项→反方审阅→确定可执行优化建议。真实独立子Agent可用才称独立反方；否则明确“单模型隔离式反证”，并针对每条重要问题寻找合理反证。

问题按P0（主线或核心因果不成立、重大设定矛盾）、P1（明显损害留存的结构性缺陷，如长期乏味、主角失去主动性或冲突疲软）、P2（局部因果、节奏、动机、伏笔缺陷）、P3（体验增强机会）分级。每项写**卷/情节位置、当前设计、问题原因、读者影响、修改动作、牵连范围与风险、预估净收益与价值**；禁止“加强冲突”一类空泛方案。方案的收益必须大于损害，已成立设计应建议保留。重大情节变化交作者裁决。

### 五、最终交付格式

1. **相邻上游/权威约束一致性验收**：锁定决议与总纲逐项映射、有效版本、通过/打回/待核实及修复方向（打回时不得宣布可进入卷纲阶段）。
2. **综合评价**：可验证总分/100（或因缺资料无法形成总分）、等级、三个优点、三个最重要问题、最大弃书风险、能否进入第二阶段“分卷章纲”。
2. **16维评分表**：原分、权重、折算、证据和不适用/待核项。
3. **全书各阶段/各卷矩阵**：目标、冲突、亮点、回报、追读钩子、缺口、相邻卷承接及阶段评价；只能对可读材料形成结论。
4. **开篇前3／前10章专项**：真实覆盖或资料不足声明。
5. **P0—P3问题台账**：具体原设计证据、反证、位置、风险、最小建议。
6. **最高价值修改方案（最多10项）**：不足10项按真实数量，不强凑；给出替代情节方案、收益维度、代价、影响范围。
7. **最终编辑意见**：作品独特卖点、最大弃书风险、通俗与精彩程度、主角魅力、长线追读能力、应保留的优秀设计，以及只允许改三处时的优先选择。
8. **执行状态**：实际读取范围、反方方式、缺失资料、报告存放位置（若已实际保存）、未修改源文件的说明。不得谎称执行了不存在的子Agent、文件写入或验证。

**执行约束**：只审不改；不根据旧报告分数下判断；对未写细纲不虚构具体章节；不给规划材料套正文七维评分、37项语言AI味或正文TXT导出；作者未明确授权写报告时只输出报告，不改仓库。请直接执行，不必逐项征求确认。
