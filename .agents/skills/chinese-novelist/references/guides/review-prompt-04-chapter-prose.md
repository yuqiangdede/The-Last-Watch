# 阶段四：正式正文质量审核、正收益自动修订与同步提示词

> **调用示例**：审核【第四卷第128章正文】；审核【第四卷第128—132章正文】。对应正式入口为 [chapter-review-default.md](chapter-review-default.md)，**评分/37项定义/优化轮次只认 [review-core.md](review-core.md) 和 [ai-style-37-checks.md](ai-style-37-checks.md)**。本文件为可直接复制的用户提示词，不是新增评分制度。

## 可直接使用的提示词

请严格执行本项目 .agents/skills/chinese-novelist/SKILL.md、其 references/guides/chapter-review-default.md、references/guides/review-core.md、references/guides/ai-style-37-checks.md 及项目正式配置，对【审核对象：卷名＋章号/章节文件或多个章节】执行**完整正文质量审查、正收益自动修订、复审与文件同步**。请直接执行，不必逐项征求确认；重大剧情/人物命运/世界观改变仍须作者裁决。卷内编号、全书编号和插章按项目真实索引核对。

### 审核重点（强制）

1. **AI味专项最高优先级**：遵守正式协议的正文七维评分及AI味37项独立裁决（**AI味专项不是数值评分，也不换算AI生成概率**），尤其重点核查自然中文、人物对白、段落级叙事真实性、翻译腔和模板化表达。
2. **只执行正式实际存在的37项**，重点复核其中高风险条目，不自行补造规则、不把旧G1—G4叠加成独立门禁，也不一处问题多次扣分。
3. **逐自然段完整语义审阅**：结合邻句、场景和读者体感检查叙事增量、句式/动作/心理解释重复、抽象概括、读者是否需要回读、常见搭配与指代；登记完整覆盖范围，不只跑关键词或正则。
4. **人物对白逐句校验**：按人物身份、性格、立场、文化背景、现场情绪、关系及知情限制辨别声口；检查公文腔、免责腔、程序化汇报、同场角色同口吻，保留必要的职业语言和真实口语特点。
5. **剧情独立审查**：按因果、人物主动选择、实际代价、信息边界、节奏、读者期待、世界观、时间地理、资源/装备、物理与专业常识、前后章连续性逐一核验；不要只检查语言。
6. **独立反方或如实降级**：有真实子智能体才使用独立反方审阅；否则明确标为“单模型隔离式反证审查”。反方提出最强质疑及保留原文的最强理由，主审独立核证。
7. **待复核必须查证**：针对“明显、待复核、证据不足”的规则及剧情问题查上下文/设定，逐条给裁决与处理结果；不直接忽略，不凭机器候选自动定罪。
8. **最小净收益改稿**：对已证实的实质问题，先比较改善与人物、情绪、节奏、伏笔、事实链损害；收益明确大于损害才修改，优先最小语句/局部段落修法。允许零修改，不为凑数量强改；重大改动暂停待作者裁决。
9. **正式优化闭环**：按 review-core.md 当前存在的实际阈值、最多轮次、补优化、回滚、停止条件进行初审→修改→复审；优化变差立即回滚并记录。不得自己发明新的及格线。
10. **受影响范围复核**：重新核对修改段落、邻段、人物声口、剧情因果、专业与物理限制、AI味37项的受影响规则、必要的相邻章节及伏笔。改稿后专项结论基于改后证据重判。
11. **正式文件同步**：先确认唯一正文源；依项目真实工具和路径同步 Markdown、TXT 单章阅读副本和分卷合订本（如果项目要求），检查标题/顺序/字句/段落/文件内容一致。未运行的导出/校验不可报已通过；只有远程GitHub文本写入能力时，明确说明本地工程验收障碍。
12. **完整留痕**：生成或按项目规定保存审查报告、逐项37条裁决、七维原始分/折算分变化、问题台账、净收益/风险、修改前后差异、优化轮次、回滚记录、未解决问题和验收状态；按项目正式规则维护章节最终审核总表，不能用对话分数冒充已写入Excel。

### 执行约束

- 以本次项目最新正式协议和权威事实为准；发现文件或规则相互冲突，展示证据并按权限处理。
- **本次必须独立重新评分**。不查看、不继承、不以任何上次总分/分项分作为评分锚点；允许读取此前的问题台账作为线索，但所有问题及分数均以本次原文阅读重判。当前审查形成的初审分数可与**本次修订后的复审分数**比较。
- 不因为数值分数高而忽略AI味专项，不为降低AI味破坏合理人物语言、情绪、节奏或剧情逻辑。已证实优秀的内容保留。
- 无正收益改法则允许零修改，并注明原因；确证重大问题不能安全修复时保持待裁决/未通过，不虚报交付合格。
- 不虚构子Agent、读取、工具调用、脚本运行、文件写入、评分依据或验收结果。
- 用户本次明确授权直接修改时，按当前项目的 Git 规定**在当前目标分支直接修改、自动提交并推送，不创建PR**；严禁覆盖无关工作区改动、强推、跳过远端并发冲突检查。只有实际写入/提交成功才能称同步完成。若项目另有授权规则或本次明确只读，按本次授权处理。
- **既有正文的审查/最小修订不因历史上游规划缺项而一概阻断**，但必须提示缺失所导致的连续性核验风险；不擅自补造情节。
- 只有必须由作者决定的重大情节、命运或世界观问题才留待裁决；其他确证且可安全修的问题在授权范围内直接处理。

### 最终交付

明确展示：①审查对象、真实文件版本、实读段落覆盖与反方方式；②剧情与世界连续性结论；③本次**初审与复审**正式七维评分及加权总分；④AI味37项专项结论（有问题项逐条摘要，37项全表留报告）；⑤真实修改数量、关键“改前→改后”、净收益及优化轮次；⑥回滚及未解决问题；⑦MD/TXT/分卷合订本实际同步、校验命令和结果；⑧总表更新状态；⑨完整审核报告**实际路径**及当前分支/提交SHA（只有实际创建时提供）。
