# 小说项目 AGENTS.md 通用规则模板

项目 AGENTS.md 用于保存当前作品的工作流程、权威资料路径和作者确认的特殊要求。**本 Skill 只提供通用模板，不把安装它的仓库的某部作品设定复制到新项目。** 下列路径仅为示例，应按项目实际配置调整。

```markdown
# 小说项目创作与审查约束

## 1. 资料权威顺序
- 已定稿正文：已经发生的事实。
- 已确认人物与世界设定：后续写作需要遵守的规则。
- 大纲、任务卡、简写：尚待发生的计划，与正文冲突时须核实。
- 项目专属规则：作者指定的文风、题材约束和技术条件放在本项目文件中。

## 2. 写前准备
- 确认待写章节、已发生情节及实际版本。
- 根据需要读取相关人物档案、世界规则、章纲与简写。
- 核查人物当前状态、知情边界、空间时间、已有伏笔。
- 尊重作者确认的视角、风格和叙事节奏，不推定固定题材。

## 3. 写作与校验
- 按项目确认的写作顺序和唯一正文源操作。
- 对行动、环境、物态、技术参数与资源使用检查物理常识。
- 审查人物行为、情节因果、自然中文表达和有效场景信息。
- 具体裁决依 chinese-novelist/references/guides/review-core.md。
- 问题成立且改动净收益明确为正时才实施最小修订。

## 4. 写后回写
- 记录正文实际发生的事件、人物状态、地点、资源及伏笔。
- 根据当前项目配置同步必要副本、索引和审稿报告。
- 不得宣称未执行的脚本、校验或独立审阅已经完成。
```

**特殊题材与特殊文风**：允许在各小说项目自己的 AGENTS.md 或项目配置文件中明确定义，但不得成为 Skill 的跨作品默认硬约束。小说可采用不同视角、语言风格、情节结构及职业活动。
