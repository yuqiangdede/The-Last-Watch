# 阶段二：分卷章纲质量审核提示词（只审不改）

> **调用示例**：审核【第04卷分卷章纲】；审核【第四卷第128章章纲】；审核【第四卷全部章纲】。本阶段的“分卷章纲”包含卷级目标和单章纲要；16维量表按 [outline-review.md](outline-review.md) 的分卷章纲口径执行。不是全书大纲，也不是章节简写。

## 可直接使用的提示词

请严格执行本项目 .agents/skills/chinese-novelist/SKILL.md、references/guides/outline-review.md 及项目正式配置，对【审核对象：指定卷、指定章纲或连续章纲范围】进行**分卷章纲完整剧情审查**。默认**只审核、只提出具体修改方案，不直接修改源纲要**；已完成正文是不可随意改写的已发生事实。

### 一、目标与范围

以**普通目标读者能看懂、愿追读、有回报**为核心，检查卷目标是否落实到各章；单章目标、冲突、选择、结果和代价是否能持续推动主线。尊重类型（含不靠爽点驱动的作品）；不能强制每章反转、打脸或战斗。

先读项目规则、全书大纲／主线、对应卷纲与目标章纲、必要人物设定、世界规则、伏笔和当前已定稿事实，并登记来源与版本。整卷／连续章纲必须逐章覆盖；只审一个章纲也须查看上下章承接和本卷目标。**分清全书连续编号、卷内编号和插章**，使用项目现行对照，定位不明确时核实而非猜。若卷纲存在而章纲为空、章纲不包含有效事件或只有只读汇总索引，标记缺失/待核实。

### 二、16项审核与评分

按照 outline-review.md 正式**16维、100分**评价：通俗易懂8、情节跌宕8、钩子与追读欲10、阅读低负担8、设定合理性6、题材特色与知识价值5、情节因果逻辑10、主角魅力与主动性7、爽点与成就感9、冲突与对抗6、新鲜感与想象力6、人物关系与情感4、节奏与结构4、悬念与伏笔兑现4、前后一致性3、作品辨识度2。逐项给0—10、权重折算和该卷/章可引用的证据；9—10优秀、7—8良好、5—6一般、3—4较差、0—2严重不足。**证据不足项不凭空打分**；完整总分只有全部维度可评价时才给出。全书宏观维度在单章级无法验证时可注明不适用，不把规划粒度不足当作故事缺陷。

### 三、分卷与逐章专项

1. **分卷目标落地**：本卷在全书主线中的作用、开局状态、阶段性冲突与高潮、不可逆变化、结尾向下卷的承接是否具体；不重演上卷同款任务。
2. **每卷卷首强钩子（必查）**：卷纲是否明确卷首具体情节，第一章是否立即出现有利害关系的异常/冲突/变化，前3章是否有人物选择、实质后果与首轮回报；审查读者迫切追问什么、钩子怎样推动本卷核心冲突、是否与上卷事实接续、是否又用了同款套路。不得以一条神秘台词或“加强悬念”等空话充数；未实读卷首材料时写“待核实”，不可报已通过。
3. **逐章剧情六要素**：每章目标→阻力→人物主动选择→代价→新局面→下章期待；核查起因、动机、条件、行动、阻碍、结果、代价的完整性，短章/慢章有具体功能即可。
4. **情绪回报与钩子**：开章期待、关键转折、阶段结果是否落地；悬念多久有回报，是否不断拖延；反转是否有铺垫，安静章节是否有关系/信息/情绪变化。
5. **人物与对抗**：主角及配角是否会自己做选择、犯合理错误、付出代价；对手的目标、资源和制约是否成立，是否通过降智或空降能力解决矛盾。
6. **世界／事实／时序**：跨章地点、时间、受伤状态、装备物资、知情范围、阵营关系、世界规则与已经发生的正文是否兼容；明确写出的物理参数及专业步骤按可核条件验证，不捏造未写细节。
7. **反同构**：比较各章事件、选择和结果的组合；找重复冲突、功能性角色、情绪固定流水线、用新设定堵漏洞等PLOT01—07风险，并写出真实阅读损害。只审剧情结构，不审正文语言37项。
8. **开篇专项**：审核全书前3／前10章只在审核范围与实际材料支持时进行；若本次审的是中后卷，重点改为本卷前几章的进入门槛与卷末追读动力，不编造全书开篇覆盖情况。

### 四、反方、问题与改法

完成独立重新判断，不沿用历史审核分数；旧问题只作核实线索。可真实委派独立子Agent才委派，否则标“单模型隔离式反证”，逐条对读者损失和修改价值寻找反证。P0—P3按 outline-review.md 的规划标准裁决，注意单个弱钩子不等于主线P0。每个问题必须给出**卷章/具体段落、当前剧情、缺陷、读者影响、明确的替代安排、代价与对后续卷章的连锁风险、建议优先级**。改善收益不足或损害已定稿事实的建议不得冒充必改项；重大改动交作者裁决。

### 五、交付报告

- 目标范围、读取文件/版本、实读覆盖章节数、上游材料缺失/待核实项。
- 初审16维原始分和权重折算表、总分（完整可评时）、优点、主要弃书点、能否进入“章节简写”阶段。
- **卷首强钩子核查结论**：卷首第一章事件、前1—3章的利害/问题/选择/后果、与本卷主线的联系、实读证据、缺项与就绪度；若只审中段单章，写明该项未核实。
- 卷级结构图解／文字矩阵及**逐章审查表**：目标、阻力、选择、代价、新局面、钩子、风险、简写就绪度；单章审核则聚焦该章与前后章。
- 分级问题台账及具体修法、反方攻击与主审裁决、可保留的精彩设计。
- 高价值可实施改法（最多10项，不凑数）及“只能改三处”的优先顺序；对应后续计划和事实风险。
- 作者待裁决问题、实读/未读边界、报告实际保存情况；不虚报修改或工具验证。

**执行约束**：仅审不改，不把正文或简写缺少华丽对白当问题，不套正文七维／37项语言规则／TXT交付；如目标材料不完整，按已有粒度审查并说明影响。用户另行明确要求修订且授权时才转入正收益小范围修订并按项目更新章纲派生索引，不得在本次“只审”中暗中修改。请直接执行。
