# 深度世界观构建指南（跨题材通用）

不同作品可以采用不同范围和复杂度的世界设定。**不默认存在战争、阵营、特殊能力、超自然现象或任何固定技术水平。** 只为正文实际需要的设定建档，具体规则均来自当前作品配置与已确认正文。

## 一、可选专题分类

1. **世界观总纲**：题材、现实与虚构的区别、世界运行的一般条件、主要人物所处的基本环境。
2. **历史与时间线**：采用什么纪时方式，重要事件发生在何时，过去事实怎样影响现在；没有自定义纪年时可用普通时间。
3. **地理与环境**：地点、相对位置、交通、气候及必要的距离和耗时；不要求存在世界地图或跨国地理。
4. **社会与组织**：家庭、社区、职业、机构、群体间的关系与利益；没有大型组织时不强制设计。
5. **能力与限制**：角色知识、技能、资格或作品专有的超常能力；说明使用条件和边界，普通现实题材无需能力分级。
6. **物品与技术**：关键器物、工具、服务或技术的用途、使用条件、代价和维护；只记录实际涉及的内容。
7. **经济与生活**：居住、工作、食物、交换、社会习惯及资源限制；依据叙事需要决定细节深度。
8. **特殊设定（可选）**：科幻、奇幻、架空等题材另有的法则；不出现则标不适用，不要求强行设置异常事件。

以上是分类建议，不是每个小说必须维护八个文件。文件名、实际路径与是否合并专题由项目配置决定。

## 二、每个设定的基本记录

- 名称及定义：什么对象、关系或规则。
- 使用场景：哪些情节真正依赖该规则。
- 已确认事实：引自哪章正文、作者说明或权威设定文件。
- 可观察表现：读者能通过什么行动和后果理解它。
- 限制与成本：相关时间、物资、身体、制度或特殊条件。
- 未确认内容：作为作者待定项，而不是自动补设成事实。

## 三、维护原则

1. **一处权威来源**：同一设定避免在多处维护矛盾版本；确定当前项目的权威资料与优先级。
2. **按需加载**：仅为待写章节读取相关专题；小场景不要求全世界资料铺陈。
3. **物理常识核查**：能验证的温度、距离、速度、负重、人体状态、能源和资源平衡按 [统一核心协议](review-core.md) 检查；已确立的虚构法则须说明何处例外。
4. **事实回写**：只在正文已发生或作者正式确认后更新设定；未定的计划保留待确认。
5. **禁止跨作品污染**：不得复制安装本 Skill 的仓库中任何具体作品的人物、地点、势力、文风、技术或情节作为另一个项目的默认设定。
