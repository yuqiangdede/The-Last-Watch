# 章节最终审核总表维护规范（Markdown 唯一权威源）

> 本文规定怎样持久记录每章已经完成的正文审核结果，不是新的质量量表、独立审核关卡或免审捷径。质量评分、AI味37项裁决、P级、复审与门禁以 `review-core.md` 为唯一依据；执行步骤以 `chapter-review-default.md` 为准。不得用统计表反向篡改正式审核报告。

## 1. 唯一文件与维护方式

- 唯一权威文件：`08-审稿/章节最终审核总表.md`。
- 该文件是 Markdown 纯文本，直接通过 GitHub 或 Codex 编辑；不维护 XLSX、CSV、JSON 或其他机器镜像，不依赖 Python 生成器。
- 对正式正文完成一次有证据的审查/复审并形成正式报告后，同次交付内更新总表。单章更新一篇，多章/整卷只更新实际完成审查且有正式报告的篇目。
- 一个篇目一条当前结果。再次复审时更新该篇目的索引行和详细记录；历史轮次保留在各轮报告及 `05-写作计划/阶段审核记录.md`，不得覆盖或删除。
- 只有 GitHub 文本编辑能力时可以直接维护；无法核实的字段写“待核实”，不得以无法运行脚本为由把真实文本更新说成自动校验通过。

## 2. 每篇必需字段

| 分类 | 字段 | 规则 |
| --- | --- | --- |
| 定位 | 作品、卷、章节号/插章标识、标题 | 使用当前项目真实正式标识 |
| 源稿证据 | 正文MD路径、基线版本/commit、正文SHA256 | 记录本次实际受审源稿；缺失则明确待核实 |
| 报告 | 最终审核报告路径、审核日期 | 必须指向仓库内真实存在的报告 |
| 评分 | 初审总分、最终总分、分数变化 | 正式正文七维加权总分，0—100，最多一位小数 |
| 七维 | 剧情因果、时空行动与物理合理性、设定及跨章连续性、人物群像、节奏可读性、语言自然度、悬念伏笔 | 记录最终复审每项原始0—10分 |
| AI味 | 专项结论、明显项数、待复核项数、证据不足项数 | AI味不设分数、百分比或生成概率 |
| 问题闭环 | 初审确证问题数、确认修复数、最终遗留问题数、P0/P1数、修订落点数、优化轮次、回滚次数 | 同根因只记一项，按正式报告记录 |
| 独立结论 | 文学质量、上游一致性、工程交付、总体验收 | 分开记录；总体验收不得覆盖单项阻断 |
| 阅读副本 | 单章TXT状态、分卷合订本状态 | 逐字核对后才可标记文本核对通过 |
| 反方 | 反方审阅方式 | 独立子智能体与单模型反证不得混写 |
| 钩子 | 钩子强度、开篇/过程/章末诊断 | 如本轮执行独立诊断，注明不并入正式总分 |
| 备注 | 遗留问题摘要、最近修改日期、补充说明 | 写清待作者裁决和未核实事项 |

**正式正文七维固定权重**：剧情因果20、时空行动与物理合理性15、设定及跨章连续性15、人物群像15、节奏可读性15、语言自然度15、悬念伏笔5。各项原始分0—10；总分按 `Σ(原始分 × 权重 / 10)` 计算，最多一位小数。AI味37项专项独立裁决，不计分。

## 3. 总表组织格式

文件顶部维护“当前结果索引”，建议列为：

| 卷 | 篇目 | 标题 | 初审→复审 | AI专项 | 文学质量 | 工程/总体验收 | 报告 |
| --- | --- | --- | --- | --- | --- | --- | --- |

索引后按卷、篇目维护逐篇详细字段表。修改时必须同步更新索引和该篇详细记录，避免两处数据冲突。详细字段允许按本规范第2节的分类组织，但不能遗漏受审版本、报告、七维、AI味、P级、工程及副本状态。

## 4. 单章更新事务

1. 以本次真实读取的正式正文、对应审核报告和复审证据为依据。
2. 按“作品＋卷＋篇目标识”定位唯一篇目；首次审查才新增。不得因同章多轮审核新增重复当前行。
3. 初审分取本轮闭环基线；最终分取最后一次实际完成的文学复审。最后一次修改后未复审，不得沿用修改前分数冒充最终分。
4. 文学质量、AI味、上游一致性、工程交付、TXT、合订本分别记录。总体验收通过必须有全部适用门禁的真实证据。
5. 人工核对篇目唯一、七维加权重算与报告一致、分数变化正确、报告路径有效、SHA256没有复制错位、TXT与合订本状态有逐字对照依据。
6. 不能核实的字段留“待核实”；不伪造自动校验、脚本运行或本地环境结果。

## 5. 边界与历史

- 明确只读/只讨论且未授权仓库写入时，不修改总表。
- 旧量表分数不得机械换算为新版结果；必须重新审查才可登记新版分数。
- 总表是汇总索引，不能替代逐章完整报告、37项裁决、逐段覆盖证据和修订差异。
- 历史 CSV/XLSX 仅可作为迁移前历史材料；不得回灌或覆盖当前 Markdown 权威记录。
