# 深度人物档案与分层管理模板（通用）

本指南适用于不同题材和叙述方式，不规定角色必须属于某种组织、具备战斗技能、经历特定政治冲突或遵循固定分卷成长路线。**具体人物设定只能从当前作品已确认的档案及正文获取。** 下列字段按需填写，可增删。

## 一、建档范围与组织

主角、核心配角、重要推动者、会在多个场景出现并有独立选择的角色，建议建立独立小传；一次性背景人物可以不建档。角色身份层级和目录位置，以当前项目配置为准。

示例目录（非强制）：

```text
人物/
├── 人物索引.md
├── 主角/
│   └── 角色甲.md
├── 配角/
│   └── 角色乙.md
└── 辅助角色/
    └── 第01章-角色丙.md
```

小传是性格和因果校验依据，不是必须灌入正文的背景说明。禁止仅因角色“应该成长”就为其新增创伤、背叛或牺牲。

## 二、主角／核心配角小传（10 个可选维度）

```markdown
# 人物档案：[姓名或代号]

## 1. 基础信息
- 姓名、年龄或寿命机制：
- 首次出场与当前身份：
- 出身、职业、所处社会关系：
- 可辨识的外貌、语言和习惯：
- 视觉资料（如有，引用当前项目真实路径）：

## 2. 经历与重要变化
- 形成当前观念的经历：
- 已发生的主要事件及时间：
- 尚未确认的背景与待定内容：

## 3. 能力、专长与局限
- 生活、职业或特殊技能：
- 经验、训练与现实条件：
- 不擅长的事、体力和其他限制：

## 4. 特殊能力（作品适用时才填写）
- 能力表现及使用条件：
- 代价、冷却、限制与例外：
- 当前作品中的权威设定出处：

## 5. 性格与行为逻辑
- 表面性格与内在需要：
- 何时妥协、何时坚持、何时犯错：
- 压力下可能做的选择及原因：

## 6. 价值观与目标
- 当前具体目标：
- 长期愿望与潜在矛盾：
- 对重要事物的取舍标准：

## 7. 社会关系
- 重要亲友、同事、对手或所属组织：
- 各段关系中的利益、信任与误解：
- 角色实际知道和不知道的事：

## 8. 阶段性变化（按作品计划填写）
- 当前阶段的心理与行为状态：
- 下一个重要选择及代价：
- 后续可能变化（未定稿时注明待定）：

## 9. 长期安排与边界
- 作者已确认的长期走向（如有）：
- 不可无证据突破的能力、动机及关系边界：

## 10. 连续性禁改事项
- 不得凭空获得新能力、知识或资源。
- 不得忽视已发生的伤病、经历与行为后果。
- 不得为了制造冲突而让人物无依据转变立场。
- 不得为了迎合统一文风而消除人物合理声口差异。
```

## 三、辅助角色精简小传

适用于短期但有独立行动的角色，按需记 200—600 字，不以字数作为质量硬门禁。

```markdown
# 辅助人物档案：[姓名]

- 首次出场章节：
- 身份与社会关系：
- 对当前事件的实际作用：
- 个人目标和利益边界：
- 典型言行及需要保持的特色：
- 能力与现实限制：
- 已发生事实与已知信息：
- 后续是否复现及待定事项：
- 校验来源（正文或确认设定）：
```

**使用规则**：情节设计可以参考小传，但角色不可只作为主角的功能道具；已有正文事实优先于尚未确认的候选设定。不要把模板自带的示例误当作作品事实。
