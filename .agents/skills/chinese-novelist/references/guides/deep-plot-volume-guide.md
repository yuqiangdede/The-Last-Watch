# 长篇剧情与分卷因果规划（通用）

本指南提供可选的规划方法，不限定小说有多少卷、是否有阵营冲突、是否发生战争、人物是否牺牲或采用何种结局。项目中的卷名、卷数、情节、节奏和文风均由作者与权威规划决定。

## 一、分卷因果三问

1. **发生什么重要变化？** 是新的事件、关系变化、认知改变，还是长期问题出现了新阶段。
2. **人物为什么这样选择？** 结合其目标、局限、当时掌握的信息与可用资源，说明前后选择的因果。
3. **选择产生什么后果？** 可以是具体代价、关系改变、新能力或资源、秘密推进，也可以是阶段性的稳定；不机械强制每卷发生灾难性转折。

三问帮助发现缺口，不要求每章采用同一叙事结构。允许文学性留白、铺垫和不立即解答的问题。

## 二、分卷大纲模板

```markdown
# 第[X]卷：[卷名] 大纲

## 1. 本卷定位
- 时间跨度：
- 主要场景与人物：
- 本卷主题与主要变化（作者已确认）：

## 2. 人物目标与因果
- 关键人物及其目标：
- 重要信息与现实限制：
- 推动事件变化的选择：
- 主要后果及向后承接：

## 3. 人物关系与外部环境
- 利益、关系或外部条件如何变化：
- 哪些冲突仍未解决：

## 4. 叙事节奏（按作品需要设定）
- 需要铺垫的内容：
- 关键事件及相应后果：
- 转折或阶段性收束：

## 5. 伏笔与事实
- 已经埋下的线索：
- 计划兑现但尚未定稿的内容：
- 必须与前文保持一致的事实：
```

## 三、单章任务卡建议

```markdown
# 第[X]章 写作任务卡

- 章节标题与所属卷（如有）：
- 本章场景、时间与在场人物：
- 前章承接与人物当前状态：
- 本章要呈现的变化和选择：
- 需要交代或继续隐藏的信息：
- 对已有设定的调用与物理常识核查：
- 后续章节的实际承接点：
- 目标篇幅（可选，按项目配置）：
```

**执行边界**：任务卡是计划，不是已发生事实；有重大矛盾时对照已定正文与最新权威资料。简写通过剧情审查后再展开正文；不为了强制钩子、反转、动作场面或悲剧而改坏已有的合理结构。
