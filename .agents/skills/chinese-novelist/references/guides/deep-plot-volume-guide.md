# 长篇剧情与分卷因果规划（通用）

本指南提供可选的规划方法，不限定小说有多少卷、是否有阵营冲突、是否发生战争、人物是否牺牲或采用何种结局。项目中的卷名、卷数、情节、节奏和文风均由作者与权威规划决定。

## 一、分卷因果三问

1. **发生什么重要变化？** 是新的事件、关系变化、认知改变，还是长期问题出现了新阶段。
2. **人物为什么这样选择？** 结合其目标、局限、当时掌握的信息与可用资源，说明前后选择的因果。
3. **选择产生什么后果？** 可以是具体代价、关系改变、新能力或资源、秘密推进，也可以是阶段性的稳定；不机械强制每卷发生灾难性转折。

三问帮助发现缺口，不要求每章采用同一叙事结构。允许文学性留白、铺垫和不立即解答的问题。

## 二、卷首强钩子：每卷必设计

**每一卷都要有自己的强开局，第一章便让“值得追读的事”发生，而不是先用几章讲背景。** 强钩子是一段能真正推动剧情的事件，不只是章末悬念句。

设计时回答六个具体问题：

1. **钩子发生在哪里？** 明确卷首第几章、哪个场景；第一章就启动，原则上在前3章内产生实际行动或后果。
2. **眼前发生什么不寻常的事？** 必须给出可写成场面的事件，如证据出现、关系破裂、突发请求、重大机会或原计划失控，而非概念口号。
3. **谁会失去或得到什么？** 把利害关系压到具体人物身上，体现风险、欲望、情绪和现实制约。
4. **读者会急着追问什么？** 形成与人物命运、眼前困境或长线秘密有关的明确问题，而非故意遮掉常识信息。
5. **人物接下来必须做什么？** 前3章内应出现主动选择及可见后果，安排一轮合理的局部回报，避免不断延迟兑现。
6. **为什么只属于这一卷？** 钩子须由上卷状态自然引发，牵出本卷核心冲突、主题或人物弧线；避免各卷同款爆炸、追杀、奇人空降。

可选类型：危机与行动、真相与证据、关系与背叛、利益与交易、伦理抉择、失而复得等。**不以打斗、死人、极端反转定义“强”；以强因果、真实利害与后续推进定义“强”。** 已定稿正文事实与作者锁定设定优先，不为钩子强行改造人物行为。

## 三、分卷大纲模板

```markdown
# 第[X]卷：[卷名] 大纲

## 1. 本卷定位
- 时间跨度：
- 主要场景与人物：
- 本卷主题与主要变化（作者已确认）：

## 2. 卷首强钩子（必填；第一章启动，前三章内形成后果）
- 钩子事件（具体场景/行动）及所在章位：
- 受到冲击的人物与眼前利害：
- 读者迫切想知道的问题：
- 人物不得不做的选择及制约：
- 前1—3章的结果/代价/首轮兑现：
- 由此牵出的本卷核心冲突：
- 与上卷已发生事实的衔接、避免重复的手法：

## 3. 人物目标与因果
- 关键人物及其目标：
- 重要信息与现实限制：
- 推动事件变化的选择：
- 主要后果及向后承接：

## 4. 人物关系与外部环境
- 利益、关系或外部条件如何变化：
- 哪些冲突仍未解决：

## 5. 叙事节奏（按作品需要设定）
- 需要铺垫的内容：
- 关键事件及相应后果：
- 转折或阶段性收束：

## 6. 伏笔与事实
- 已经埋下的线索：
- 计划兑现但尚未定稿的内容：
- 必须与前文保持一致的事实：
```

## 四、单章任务卡建议

```markdown
# 第[X]章 写作任务卡

- 章节标题与所属卷（如有）：
- 本章场景、时间与在场人物：
- 前章承接与人物当前状态：
- 本章要呈现的变化和选择：
- 若处于卷首第1—3章，本章如何启动/推进卷首强钩子及其后果：
- 需要交代或继续隐藏的信息：
- 对已有设定的调用与物理常识核查：
- 后续章节的实际承接点：
- 目标篇幅（可选，按项目配置）：
```

**执行边界**：任务卡是计划，不是已发生事实；有重大矛盾时对照已定正文与最新权威资料。简写通过剧情审查后再展开正文；**卷首强钩子必须明确规划和核查，但不可机械用强制反转、动作场面或悲剧改坏合理结构**；已写正文不得因规划补丁被擅自推翻。
