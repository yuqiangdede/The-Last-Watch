# Skill 与对话插件的轻量对齐约定

本仓质量审稿与 ChatGPT 对话插件 `novel-quality-review` **共享同一版核心文案**：

- 仓库：[`review-core.md`](review-core.md)
- 插件：`skills/novel-quality-review/references/review-core.md`

真正执行仅加载该协议一次；其他 `G1—G4/S/PLOT/F/TR/TX/PAM/朱雀/频率/对话/场景` 文件均为**按需查证的经验资料**。统一五类问题，事实证据与反证共享，一条根因扣一次。正文七维与AI味分开，简写只审剧情；P0/P1与工程交付分开；评分驱动优化≤5次。

变更核心规则时应同步两个入口，不必在 Skill 主文件和每个旧文档里继续复制整段。插件版本与仓库提交号允许不同，但规则内容必须保持一致。旧审稿模板可按深度输出，不要求每次填满0—10节。历史案例不删除，不能把它们的示例变成任意作品的强制参数。

**旧文档中的“必读/强制逐关复跑”不再叠加适用**，除非项目明确有独立工程门禁；工程合规检查与文学质量审稿绝不混分。
