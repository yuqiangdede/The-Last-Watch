# 小说质量审核统一核心协议（精简版）

> 本文件是质量检测唯一执行规则；旧 G1–G4、S、F、TR/TX、PAM、朱雀、场景、频率及案例文档是**按需查阅的知识库**，不是额外检查关卡，不得逐项重复跑、重复扣分。项目设定与已发表正文优先于泛用案例。不得把“AI味”当作者身份或生成概率鉴定。

## 一、入口与证据

1. 先确认材料类型与实际可读范围：卷纲、章纲、简写走**剧情审查**；正式正文走**正文审查**；混合输入分开。对章/卷细读全文，必要时读相邻章、人物小传、势力规则、定稿主线、时间线和事实账本。已发生正文、角色误判、未批准规划必须区分。无法读到的材料不声称已检，更不能给伪精准分数或全卷 PASS。
2. 检查只走一遍：**事实与因果 → 人物与场景 → 语言与叙事模式 → 证据裁决与评分**。每个问题唯一主归因；例如“静态动作+公文腔+心理复述”归一个“没有叙事增量”的问题，不分别按 PAM、F、TR、G 再扣四次。
3. 对每个成立问题写清：位置/短引文、前后语境、已发生的阅读损害、合理反证、可执行的最小修法、改动净收益；误报、缺证据、不值得改必须允许保留。机械脚本/词频仅作候选定位；第三方朱雀仅在确实提供报告时用于片段定位，绝不换算作品分或自动判定 AI 写作。

## 二、五类问题（所有旧标签只作为子类线索）

| 主类 | 必查要点 | 合并的旧检查范围 |
|---|---|---|
| A 事实/因果 | 目标→证据→选择→后果；时空路线、伤病、物资装备、世界/势力规则、跨章前后矛盾、有限视角知情边界 | 逻辑、时空、设定、世界观、跨章、技术事实 |
| B 人物/冲突 | 各人独立利益、能力局限、动机/关系演进；对手不降智；牺牲与反转有铺垫、有持续代价 | 群像、情节套路、F 的剧情类、PLOT |
| C 场景/节奏 | 每场至少有新增因果、选择、关系、风险、情绪质感或伏笔；同构救援/战斗/手续、背景复读、信息与钩子节奏 | 必要性、叙事冗余、频率、套路结构 |
| D 表达/对话（仅正文） | **优先核查60% AI味核心的程序化绕弯、免责腔、多人声口同质化**；自然口语、人物声口；模板开尾、假对比/金句、翻译腔/公文腔、无功能修饰和比喻、过密副词、同构句式与清单式描写；段落级静态微动作/抽象解释有无新增信息 | G1–G4、S01–S12、F 的语言类、TR/TX、PAM01、朱雀表达候选 |
| E 悬念/信息 | 伏笔先埋后收、秘密与人物知识边界、设定何时透露、回报是否合逻辑 | 伏笔、情报发布、章尾钩子 |

**核心判断**：正式正文写初稿时也同步防范程序化绕弯、冗余否定与群像声口同质化，不能只在审稿时补救；不机械禁词；段落检查用“删除该句是否损失有效信息/情绪/人物？”；对白别让所有人用同款比喻、宣言或论文腔；不为降检测值改坏自然对话、事实、伏笔、慢戏和必要的专业术语。对军事、医疗等专业内容按该书世界规则核查而非外推现实结论。

**语序与压缩专项（仅正文）**：检查指代词、中心词和修饰语的位置是否使读者必须回读才能拼接关系；检查合并问句、转述或省略时，动词与对象的搭配是否清楚。例：“指给众人看战区仍保留调度权的那条”可疑，重点是“那条”后置与指代关系；“问首个联络点是谁经办，夜里谁接”需结合上下文检查经办、接的具体对象。作者偏好的调整方向是把指代或共同对象放到更顺口的位置，但候选句仍须检查搭配、语义与上下文，不作标准答案。可描述为翻译腔读感，但不可断定来自翻译或 AI；正常汉语倒装、长定语、角色口语及上下文明确的省略均不自动判错。引用原文与上下文，说明具体阅读障碍和反证；只在改动净收益为正时作最小调整，同一问题不重复扣分。

## 三、AI味专项：0—100 分（仅正式正文）

**方向：0 分最好，100 分最严重。** 这是文本中可观察的程式化语言风险，不是AI写作概率、作者身份或检测平台生成率。必须细读可用全文、按段落及人物取证。**0分**仅表示在充分审阅范围内没有发现对应风险，不能代替“未检查”；证据覆盖不足写“未评分”。历史 -100～+100、0～5 分仅保留档案，不得机械换算或篡改旧报告。

六项分别按**0—100风险严重度**评分（低分较自然，高分较程式化），按下表加权，总分四舍五入至整数；同一根因只归一次，不重复扣分。

| 权重 | 检查项 | 重点识别 |
|---|---|---|
| **20%** | **公文式绕弯与程序化叙述** | 简单事实套成汇报、审批、手续说明；若真涉及军令、交接与法律后果则保留 |
| **20%** | **免责腔、冗余否定和不确定性过度包装** | 将“不知道”改说“我不能替他们说没有”，将“不确定”叠加“仍要先问”；必要行动不得因求简而删去 |
| **20%** | **多人声口同质化** | 不同角色轮流用同款谨慎声明、责任边界、书面语；要依人物身份、目标和情绪区分 |
| 15% | 翻译腔与拗口书面表达 | 生硬搭配、抽象名词链、硬译句法 |
| 15% | 模板句式与虚假叙事增量 | 假对比、口号金句、静态微动作加解释、形式大于信息 |
| 10% | 冗余重复与修辞节奏同构 | 词句复读、比喻副词过密、机械列表与一致的段落节奏 |

**计算：** AI味总分＝前三项分数之和×0.20＋第四、第五项之和×0.15＋第六项×0.10。前三项合计**60%**，其他40%。若只有单一发声角色而无法评价多人声口，标“不适用”，其余适用项按原权重比例归一；不能把“不适用”填0分。每项参考锚点：0无可辨风险；10零星；30局部多处；50多个段落/场景持续影响阅读；70跨人物、跨场景普遍出现；90大面积主导；100几乎通篇由该模式支配。不必机械采用整十档；依据证据说明分数，避免伪精确。

**判定：** 0—19低风险/通过；20—39可疑/段落复核；40—59明显/需要优化；60—79较严重/优先整改；80—100严重/程式化占主导。工程交付门槛以**≥40**为专项不通过，20—39先复核；与文学质量P0/P1无直接等价关系。**若前三项任一≥60，且在两个场景或两名角色中反复出现，即使加权总分未到40，也必须独立列高风险问题并人工裁决**，避免均分掩盖重要问题。

真正的军令、合同、交接和职责边界允许正式：不能看到“不能”“仍要”“先问”就扣分。判断它有没有真实信息/行动、有无符合角色的说话方式，改后是否丢失关键含义。对白、转述、旁白分别审；多人对话比较各人声口，不把所有角色都改成短句。写第一稿时同样执行这一规则。

## 四、两种量表与裁决

**正式正文七维（每项 0–10 分×权重/10）：**剧情因果20；时空物理战术15；设定装备跨章15；人物群像15；节奏可读性15；语言自然度15；悬念伏笔5。满分100，最多一位小数。另给**独立AI味风险分 0—100**，严格按上节**核心60%＋其他40%**的六项评估与分段裁决，越高越严重；0分仅指充分审阅后未发现对应风险，证据不足记“未评分”。必要时另给冗余0–5与重复0–5，均只是诊断，不新增总分维度。分数必须来自实际阅读范围而非脚本。多章逐章报告，卷平均仅作参考，不能掩盖单章低分。

**卷纲/章纲/简写七维（各0–10分）：**因果冲突20；钩子追更20；人物弧线15；势力世界15；节奏必要性15；情节原创与套路10；跨章伏笔5。只检查剧情设计，**不运行正文的词句、修辞、PAM、TR、G1–G4、朱雀、字数门禁与语言 AI 分**；可诊断情节模板化0–5。不得因概要缺完整对白/感官描写而扣分。

**问题分级：**P0关键事实/主线崩溃；P1重大因果、人设、时间/规则冲突；P2局部影响阅读；P3纯润色。只有**确证、实质影响作品成立的 P0/P1**使文学质量 `BLOCKED`，证据不足 `待核实`，其余为 `PASS`。**工程交付**另核审批、长度、MD/TXT、事实回写及项目脚本门禁；正文AI味≥40为专项不通过并可阻断工程交付，20—39须人工复核，但不自动制造文学P1。长度只作中性提醒，绝不进入质量七维或P级。

## 五、改稿授权与最多五次闭环

用户主动提出“审查/检测/复审”且未限定只读，即授权**有正收益的小范围定向改稿**；只读、讨论意见、权限不足、无法完整读取、需改变重大已定剧情时不擅改。先记录同范围基线分，按**单章**执行：

- 初分 **>80**：仅优化一次，检查副作用后结束。
- 初分 **75–80（含边界）**：仅优化一次，检查副作用后结束。
- 初分 **<75**：按“优化→同量表复审”循环；**复审>75后再补一次优化**并核查，才结束；恰好75不算达标。**最多执行5次优化（包括最后补充）**。第5次才首次达到>75但无法补一次，立即停下请用户决定；不得第6次自动改。

每次只改净收益明确为正的点。证据不足、无有益改法、连续没有改善、出现作者需裁决的冲突时提前停；变差则回滚，不为完成次数硬改、不虚增评分。全程记录“前分→改动→后分/复核→回滚/保留→剩余次数”，不宣称没改过的文件已修改。通常写作后的工程机械校验（原3轮）**不是此5次质量优化闭环**。

## 六、报告最小结构

1. **范围/依据/可信度**：读了哪些文件与章节，哪些没有，版本及真实委派/脚本/第三方检测状态。
2. **结论与双状态**：七维分项和总分；正文AI味0—100的六项分、加权总分、核心60%证据和判定门槛；质量 PASS/BLOCKED/待核实，工程交付独立注明；多章逐章列。
3. **问题与反证**：按 P0→P3，只写有证据且值得作者关注的问题；一条根因一条问题，给位置、短引文、影响、保留理由和最小修法。必要时附跨章事实链和场景删减损失。
4. **已执行优化/复审**：前后分、实际文件改动、核验范围、回滚、未解决问题与终止原因；注明必须保留的有效内容。

默认采用紧凑报告；用户要求深度或问题复杂时可展开旧0–10节模板。能真实委派独立反方时委派，否则只能做单模型反证并说明降级，不能假称多个 Agent。旧参考按需进入：翻译腔、段落虚假意义化、研究叙事、朱雀案例、场景自然度与重复频率；**不是每次必读清单**。
