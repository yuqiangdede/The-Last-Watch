# 设定维护的文件范围与权威矩阵

本文件为通用方法；项目专属目录、章数与人物关系以项目文件为准。当前《崖边戍卒》明确有20卷；运行时检查第01至第20卷，不得只扫描前几卷。

## 权威源

| 事实领域 | 首选权威 | 关联交叉核对 |
|---|---|---|
| 世界结构、七席、制度、地理、科技、资源 | `01-世界观/` 当前已确认主档 | 项目规则、全书主线、卷纲、章纲、任务卡 |
| 人物静态经历、身份、能力、关系与禁令 | `02-人物/` 独立小传和总表 | 事件发生时的正文事实、卷纲、章纲、动态账本 |
| 全书阶段目标和已锁定结局 | `03-剧情/全书主线.md` 与作者明确确认决定 | 卷纲导航、独立卷级细纲、章纲 |
| 卷目标及跨卷因果 | `03-剧情/卷大纲.md`、对应卷级细纲 | `03-剧情/章大纲/第NN卷.md` 逐章唯一源 |
| 逐章剧情安排、章数与状态 | `03-剧情/章大纲/第NN卷.md` | 仅生成的章节规划总表、任务卡和简写 |
| 已经发生的动态事实 | 已定稿 `06-正文/` （只读事实证据）及 `07-创作记忆/` | 小传及后续规划；正文不可改 |
| 简写中的计划性细节 | `05-写作计划/章节简写/`（只读参考） | 章纲；简写不可改 |
| 只读索引/派生物 | `05-写作计划/章节规划总表.md` | 绝不逆向覆盖章纲 |

**并非全局固定的单一文件排序。** 作者最新明确确认是最高决策证据，但对于已发生正文的追溯改变，必须核查是否明确批准；未获批准不能重写既成事实。权威主档、同级已确认版本与精确修改时间要合并判断，不能用另一个派生文件晚同步的时间反超主档。

## 扫描与修改边界

- 逐文件扫描：01、02、03（包括全部卷级细纲和章纲）、04相关小说规则、05任务卡和非简写规划、07动态记忆；对有效根目录设定性材料和配置做交叉核查。
- `05-写作计划/章节规划总表.md` 是生成品，重新生成而非直接修改。
- `07-创作记忆/作者人工复核进度.md` 保持作者独占控制。
- `06-正文/`、`06-正文-TXT/`、章节简写、历史归档是只读参考；历史资料不可作为现行生效结论，也不可修改。
- `08-审稿/` 中历史报告是线索，不是权威来源；新报告写入 `08-审稿/设定一致性维护/`，勿把旧问题原封不动当作本轮已核实事实。
- 被排除的文件仍须通过用户确认的“已发生事实”或当前规划引用进行必要比对；**排除写入不等于排除读取**。

## 章号兼容

作者要求阅读版按卷编号，但部分旧规划、任务卡仍使用全书连续内部号。跨文件检查须建立“卷号 + 全书号 + 卷内号 + 插章位置”映射，缺少映射时记待核，不把同名第001章视为同一章，也不把插章误算为普通编号章。

## 实际时间与来源

更新每份有效设定文件时写唯一的 `最后修订时间：YYYY-MM-DD HH:mm:ss ±HH:mm` 和**仅最新一条** `## 修订记录`，写明本次修改项、前后差异、来源、确认状态。旧修订条目不在现行文档叠加，历史依据回查 Git。缺时间记“历史版本，修订时间待核实”，可用 Git 历史辅证，不杜撰历史日期；只读扫描不得改时间。
