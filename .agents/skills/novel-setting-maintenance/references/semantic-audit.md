# 语义冲突全量检测矩阵
> 最后修订时间：2026-11-06 13:54:23 +08:00

本规范要求 **Agent 逐文档语义审读**。 `scripts/audit_setting_structure.py` 只负责确定性覆盖与候选证据，不能证明不存在语义冲突。

## 八类强制检查

1. **人物**：身份、既往经历、入队退队、阵营、家庭关系、技能边界、伤亡及其他关键状态；区分事件发生前后状态。
2. **世界观**：势力数量、隶属、地理交通、生产贸易、医疗科技与超常机制、组织制度、资源消耗和约束。
3. **事件**：起因→行动→阻力→结果→代价，参加者、地点、谁知道什么、哪些事件已经发生。
4. **时间线**：卷际接续、章际顺序、人员同一时刻是否多地出现、死亡后是否仍被写作在世、转场成本；不能仅按章节编号判断叙事时间。
5. **规划层级**：全书主线→卷纲导航→独立卷级因果细纲→逐章章纲的目标、章数、结局、人物弧线、卷首钩子与卷末承接；逐章目标应与卷级目标不矛盾。
6. **版本**：已确认/未确认、修改时点、历史记录/当前正文、原始确认来源；同秒冲突或无时间不擅自判断。
7. **下游同步**：人物/世界设定变化是否覆盖有效章纲、卷级细纲、任务卡、动态账本；生成索引是否与最新章纲一致，简写和正文只读。
8. **工程**：章号双体系、插章是否不占编号、链接是否指向现行位置、生成索引漂移、孤立/重复主档、迁移后旧路径引用。

## 卷纲与章纲专检（必须逐卷）

- 检查 `03-剧情/卷纲/卷大纲.md` 全部卷次和卷级主题；读取同目录所有卷级因果文件，识别待审/已确认状态。
- 对每个 `03-剧情/章大纲/第NN卷.md`（第07—10卷使用现行 `第NN卷-新版.md`，第11—15卷旧稿已清理、应登记待建） 实读全部章节行及独立插章设计，至少记录：卷号、全书/卷内编号、剧情状态、主驱动力、人物选择、转折、结果、与卷纲冲突位置。
- 与前卷最后章节、后卷第一章节交叉核对，避免未铺垫的地点跳跃和已经死亡角色突然恢复。
- **不把未写计划当作已发生事实**；不同时间的角色变化不是冲突。作者留白不由审查 Agent 自创剧情填充。
- 检查每卷起始强钩子要求是否在卷纲与章纲同向；这是规划同步项，不在设定维护任务里追加文学评分。
- 完整覆盖不等于都无问题；若某卷无章纲或无法读取，必须报告该卷未审及阻塞情况。

## 候选证据结构

每条：`conflict_id`、`entity`、`attribute`、`valid_time`、`volume/chapter`、`source_a(path,line,exact_text,revision,status)`、`source_b(...)`、`type`、`impact`、`counterevidence`、`decision`、`resolution`、`related_files`。

先独立反证：“是否是人物成长/情报误差/旧记录引用/旁观者误解/未确认方案？”再判成立、排除或待裁决。脚本命中的旧路径或不存在的链接通常只是**候选**，不要机械替换历史修订日志。
