# 《崖边戍卒》章节审稿与质检标准规范

> **对齐标准**：依据《文风与叙事规范 V1.0》第 8 节（生成前检查）与第 9 节（完成后的检查）制定。
> **适用对象**：章节创作 Agent、审稿 Agent、人工核验。任何章节必须在生成前通过 6 项前置核查，写后通过 8 项质检，方可判定 PASS 归档。

---

## 一、章节生成前检查清单（Pre-flight Checklist）

在开始撰写任何章节前，必须逐条核对并确认以下 6 项连续性要素：

- [ ] **1. 世界观及时间线核对**
  - 确认本章发生的年代纪元（2145新元）、季节气温、地理具体坐标（七折岩/主城/断层）；
  - 确认当前两大巨头（弘毅领与锐科合众）在此区域的兵力态势与政治摩擦等级。
- [ ] **2. 剧情大纲与章节目标核对**
  - 读取 `03-剧情/` 当前卷大纲与 `05-写作计划/章节任务卡/第XXX章-任务卡.md`；
  - 明确本章的核心事件与必须完成的一项叙事推进（【剧情】/【关系】/【悬念】）。
- [ ] **3. 出场人物档案核对**
  - 读取本章出场角色的独立主档（`02-人物/[角色名].md`）；
  - 核对其说话语气指纹（老霍碎嘴、林霰脆快促狭不粗俗、陈渡冷硬、严恪沉重、小年怯弱）；
  - 严禁角色违背其「行为逻辑」与「禁止偏离清单」。
- [ ] **4. 已有剧情摘要与人物关系状态核对**
  - 读取 `99-章节摘要.md` 与 `02-人物/人物关系与冲突.md`；
  - 确认本章开始时，队员之间的好感度、信任度、心结或误会处于哪一阶段，严禁信任度跳跃。
- [ ] **5. 动态连续性信息核对（任务、装备、伤情、弹药）**
  - 读取 `07-创作记忆/人物实时状态.md`；
  - 确认陈渡的右肺负伤程度、外骨骼铰链磨损度、林霰反器材弹药剩余枚数、电台电量与止痛片余量；
  - 严禁违背上一章的伤病状态（如上一章腿骨折，本章绝不能活蹦乱跳奔袭）。
- [ ] **6. 尚未回收的相关伏笔核对**
  - 读取 `03-剧情/伏笔与秘密.md` 与 `07-创作记忆/伏笔兑现记录.md`；
  - 明确本章是否有需要呼应、深化或按计划兑现的旧线索。

---

## 二、章节完成后的 8 项质检清单（Post-flight QC Matrix）

初稿生成后，必须逐条进行严格审查。命中任意严重缺陷即判定为 **BLOCKED**，必须定向重写修复：

| 质检维度 | 核心核查标准 | 判定基准与红线 | 结果（PASS/BLOCKED） |
| :--- | :--- | :--- | :--- |
| **1. 整体可读性与吸引力** | 本章是否通顺好读？是否有吸引读者持续阅读的悬念、张力或情感锚点？ | 严禁生涩拗口、假大空抒情或流水账记叙。前500字必须有情境代入感。 |  |
| **2. 人设一致性与适度变化** | 人物是否符合既定性格，又在此次事件中产生了微妙的反应或变化？ | 严禁全员哲学家化、严禁所有角色说话语气趋同；台词必须带生活毛边与性格指纹。 |  |
| **3. 去说明书与去说教** | 是否出现不必要的设定罗列、重复解释或全知心理说教？ | 严禁作者跳出来给读者上课；严禁角色在心里解说成长；武器参数服务于战斗。 |  |
| **4. 时空与战术行动自洽** | 战术机动、掩体站位、地理空间、物理耗时是否严密合乎逻辑？ | 严禁凭空瞬移、严禁无掩体在交叉火力网下肉身冲锋不死。 |  |
| **5. 科技与超感能力合规** | 装备技术与轻度超感是否严格遵守设定上限、代价与失效条件？ | 严禁临时增加未设定装备功能；超感必须伴随鼻血/偏头痛反噬，且受环境限制。 |  |
| **6. 连续性与大纲零冲突** | 是否与既有章节事实、人物命运终局和事件时间线产生冲突？ | 人物生理年龄、既往伤情、大纲既定命运不可违背；不能自相矛盾。 |  |
| **7. 篇幅字数与实质推进（硬性一票否决）** | 单章正文字数是否严格处于 4000—5000 中文字区间？是否有实实在在的剧情发展、关系递进或重要信息交付？ | **【硬性红线·一票否决】前四卷单章字数严格锁定在 4000—5000 汉字区间（严禁低于 4000 字，亦严禁超过 5000 字；超长必须拆章，不足必须采用三线交织充实细节）。** 严禁为凑字数增加无效风景或闲聊，字数越界或无实质推进直接判定 BLOCKED！ |  |
| **8. 自然阅读期待（自然留白）** | 章节结尾是否留下自然的行动未结或战术期待，而非机械断章？ | 严禁“他不知道的是……”、“危险正在逼近”等劣质套话，通过真实局势留白。 |  |

---

## 三、单章质检报告输出模板

每章质检完成后，在 `08-审稿/第XXX章-质检报告.md` 中留档：

```markdown
# 第 XXX 章 审稿质检报告

- **章节标题**：
- **实际字数**：
- **前置核对状态**：已核验（世界观/任务卡/人物档案/实时状态/伏笔）

### 1. 逐项审核评价
1. 可读性与吸引力：[评价]
2. 人设与对话指纹：[评价]
3. 去AI味与去说教：[评价，是否检出禁用词/假对比]
4. 战术行动与物理自洽：[评价]
5. 科技与超感代价：[评价]
6. 连续性核验：[评价]
7. 篇幅字数与实质推进：[实际字数：XXXX 汉字（严格核验 4000-5000 字强约束区间，低于4000或超过5000一票否决 BLOCKED）；实质推进了剧情/关系/线索中的哪一项]
8. 结尾期待感：[评价]

### 2. 最终判定结论
- **判定结果**：【PASS】 / 【BLOCKED】
- **修改建议**：（若 BLOCKED，列出具体段落修改指示）
```
