## 二、不同口径必须分开登记

| 口径 | 计算方式 | 可不可以直接和其他口径相加 |
| --- | --- | --- |
| 正式长期成员人数 | 该时点确认已归编、尚未退出的人员 | 不等于出动人数；待归编者单列 |
| 待归编／候补／长期同行人数 | 暂时参与或同行但正式关系未确证者 | 不自动加到正式成员口径 |
| 本场现场实到人数 | 本场景能证实亲自到场的本队与有依据的配属者 | 可包含临时配属，但须注明其来源 |
| 本场实际可用人数 | 实到者中能承担本次任务的人；随伤情、失联及任务变化 | 不等于全部现场人员 |
| 临时配属人员 | 有本次指派证据、接受明确协调安排的外部人员 | 需标注原单位、期限与结束时去向 |
| 友邻独立力量 | 各自执行任务、拥有自身指挥者的友军与保障单位 | **不得自动并入本队人数** |
| 平民／伤员／俘虏 | 行动保护、运送或约束对象，非默认为战斗力量 | 不加进可用战斗人员 |

## 四、发生人员变化时的登记规则

1. **进入名册**：在某章实写加入时，写明人物、此前归属、批准或约定依据、起始章／时间、对现有成员和指挥的影响；不得因为同行一次直接当成正式入队。
2. **离开名册**：说明阵亡、转隶、解散、退役、被俘等状态，区分永久与暂时退出；离队后可作为外部协作者但不算本队正式成员。
3. **临时配属**：记录原单位、任务起止、协调负责人、返回何处；不得因短时合作默认为永久入队。
4. **受伤、脱离接触、失联**：正式成员资格可保留，但现场可用人数立即重算；身体和装备状态细节仍写入人物实时状态。
5. **人员增多、多个行动分组**：记录谁是本场总协调者、谁负责各组、哪些任务由友邻独立执行，以及何时发生组织关系变化。只记叙事可核对的层次，不规定现实战术部署参数。
6. **报告人数**：遇到“我们还剩X人”时明确是原核心幸存人数、正式成员人数、现场到场人数还是实际可行动人数；不允许模糊混用。
7. **写后更新**：正文与人物实时状态核对无误后更新本账。若事态仍未确认（失踪、归编待批等），标记“未确认”，不能擅自记死亡或正式转隶。

## 五、重要作战章节编组快照模板（仅填写该章实际证实的事实）

```markdown
### 第XXX章｜行动名（时间／地点）
- 人物归属核对基准：截至第XXX章
- 本队正式成员：姓名……；合计X人
- 待归编或长期同行：姓名……；合计X人
- 本场到场的正式成员：姓名……；合计X人
- 本场到场的临时配属：姓名／原单位……；合计X人
- 友邻独立力量：单位／负责人／信息来源……；人数已知X或未确认
- 本场实际可执行人员：姓名……；合计X人（按任务、伤病、失联动态更新）
- 不在现场或不能行动：姓名／原因／何时发生……
- 本场指挥关系：总协调／临时分组负责人／独立友军……
- 人员归属变动：加入、暂离、伤停、归队、失联、阵亡……
- 本场结束后的人数与状态及下一章影响：
```

**执行规则**：首次涉及大型多人协同的章节建本次快照；无变化可引用上一条最近快照并写出本章差量，不需要在每一章重复整个名册。未来规划人数不进入“当前已发生”统计。变更触发时同步人物小传、组织／大纲、人物实时状态和章节任务卡，杜绝“纸面还活着却被算作阵亡”与“人不在现场却突然参与”的矛盾。
