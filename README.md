## 正文 AI 式表达统计与朱雀交叉验证

正式正文的四关检测 `scan_ai_tone.py` 默认附加离线的 [统计证据层](.agents/skills/chinese-novelist/scripts/novel_style_statistics.py)，标注句长变化、跨段重复、修饰词密度等可复核候选。多次 `--baseline` 可对照已定稿同类章节；只有明确使用 `--zhuque` 并设置 `MAKERS_MODELS_KEY` 才会上传正文到腾讯云。检测不能证明作者身份，也不自动改变质量评分或执行改稿。**简写/大纲继续只审剧情**。完整说明见 [统计与朱雀复核规则](.agents/skills/chinese-novelist/references/ai-tone/statistical-zhuque-review.md)，测试见 [test_novel_style_statistics.py](.agents/skills/chinese-novelist/scripts/test_novel_style_statistics.py)。

## 权威资料与冲突裁定

- 人物：`02-人物/` 的独立小传与 `02-人物/人物总表.md`；剧情：`03-剧情/全书主线.md` 和分卷细纲；章节进度：`05-写作计划/章节规划总表.md` 与实际正文。
- 根目录旧人物档案和大纲已清理；`00-全书二十卷章节分布与概要.md` 为未维护的旧规划快照，不能作为当前章节进度、人物命运或写作事实依据，待确认清理权限后删除。
- 冲突优先级：已写正文事实优先于旧摘要；同层级设定以可核实的最后一次有效修改为准；未写规划以最新已确认分卷细纲为准。不得因旧文件的更新时间较新就覆盖用户已明确确认的内容。

## 四阶段写作工作流（强制）

**卷大纲 → 章大纲 → 简写 → 正文**。卷级安排维护于 `05-写作计划/卷大纲.md`，逐章目标、章数及事件概要维护于 `05-写作计划/章大纲/第NN卷.md`；简写单独确认后，才可进入 `06-正文/` 创作。每阶段必须经作者确认，禁止跳过简写或未批准自动写正文。已写正文事实优先于旧规划，调整规划时同步相应卷、章大纲和章节规划总表；不编号插章不占正式编号。

## 章纲单一来源与生成规则

- `05-写作计划/卷大纲.md` 维护20卷的主题与阶段目标；`05-写作计划/章大纲/第NN卷.md` 是逐章概要、章数、章节标题与规划状态的**唯一可编辑入口**。
- `05-写作计划/章节规划总表.md` 为**只读生成索引**，禁止手动改动。每次改动章大纲后运行 `python .agents/skills/chinese-novelist/scripts/build_chapter_index.py --project-dir .`，再运行同命令加 `--check` 校验一致性。
- 写作必须遵循 **卷大纲 → 章大纲 → 简写 → 正文**；已写正文事实优先于旧概要，但应修正章大纲后再生成索引；不得把索引反向覆盖章大纲。

## 任务卡与章节简写目录规则

- `05-写作计划/章节任务卡/`：编号章节与不编号插章的具体执行任务卡。
- `05-写作计划/关键情节任务卡/`：跨章重大事件、战役及剧情转折的专项任务卡。
- `05-写作计划/关键角色任务卡/`：跨卷角色成长与关键人物弧光的计划卡；人物事实仍以 `02-人物/` 为准。
- `05-写作计划/章节简写/第NN卷/`：按卷归档章节与插章简写，下一阶段正文须经作者确认；已有汇总版可先保留，不能误当正式正文。
