## 四阶段写作工作流（强制）

**全书大纲 → 分卷章纲（卷纲先审核通过，再写章纲）→ 章节简写（章纲审核通过后才能写）→ 正文（简写审核通过后才能写）**。全书主线以 `03-剧情/全书主线.md` 等权威材料为准；分卷章纲涵盖 `03-剧情/卷纲/卷大纲.md` 与 `03-剧情/章大纲/第NN卷.md`；简写按卷归档。写作前检查当前目标阶段的全部上游材料；开始写作前须依据 [写作准入硬门禁](.agents/skills/chinese-novelist/references/guides/stage-entry-gate.md) 查核当前有效上游的正式报告、明确“通过”结果及受审版本；缺项、未通过、过期或待核时必须先审核/复审，禁止生成下游新稿（包括待审草稿），不存在“带缺项继续写作”例外。简写正式审核通过、上游齐全后才可自动进入 `06-正文/`。具体核验规则见 [chinese-novelist Skill 第2节](.agents/skills/chinese-novelist/SKILL.md)。已写正文事实优先于旧规划；不编号插章不占正式编号。

## 章纲单一来源与生成规则

- `03-剧情/卷纲/卷大纲.md` 维护18卷的主题与阶段目标；`03-剧情/章大纲/第NN卷.md` 是逐章概要、章数、章节标题与规划状态的**唯一可编辑入口**。
- `05-写作计划/章节规划总表.md` 为**只读生成索引**，禁止手动改动。每次改动章大纲后运行 `python .agents/skills/chinese-novelist/scripts/build_chapter_index.py --project-dir .`，再运行同命令加 `--check` 校验一致性。
- 写作必须遵循 **全书大纲 → 分卷章纲 → 章节简写 → 正文**，直接跨阶段时须先补齐并正式审核通过相应上游，不能只提醒后继续；已写正文事实优先于旧概要，但应修正章大纲后再生成索引；不得把索引反向覆盖章大纲。

## 任务卡与章节简写目录规则

- `05-写作计划/章节任务卡/`：编号章节与不编号插章的具体执行任务卡。
- `05-写作计划/关键情节任务卡/`：跨章重大事件、战役及剧情转折的专项任务卡。
