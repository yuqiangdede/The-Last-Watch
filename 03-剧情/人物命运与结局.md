# 《崖边戍卒》人物命运与终局预设（20卷版）

> 以 `03-剧情/全书主线.md` 为全书三阶段权威；此处只锁定命运节点，不把第五至二十卷的未细化情节当作已写正文。**前期1—4卷，中期5—12卷，后期13—20卷。**

| 人物 | 前期第1—4卷 | 中期第5—12卷 | 后期第13—20卷 |
| :--- | :--- | :--- | :--- |
| **陈渡（老渡）** | 宁昭早年战死；青隘守边并带队收留严恪、江小年；第四卷因严恪阵亡遭无证定谍，与弘毅军官冲突；在统帅部早定的北撤局势下被借题点名去任务A，林霰战死、杜衡殉节。携遗体保存设备、严恪骨灰、霍山、江小年、杜川叛逃。 | 将寻求复活林霰的可能当成活下去的理由，辗转各大体系；技术希望逐步破灭。第十二卷救江小年时重伤，此后亲自安葬林霰，学会接受活着的人与江小年彼此选择的关系。 | 率队回青隘，逐步学会政治治理与授权，继承杜衡的护民责任；带领防区发展为弘毅与锐科间区域第三势力，最终成为世界第八大势力。可以选择不受个人崇拜束缚的职务，不做君主。 |
| **林霰（灰雀）** | 凡人射术来自训练，独立热爱普通生活；第四卷守护断脊岩撤离边民，重伤短暂维持战斗后真正死亡，临终情感获得陈渡回应。 | 医学事实始终是**不可逆死亡**；陈渡携旧军用低温**遗体保存设备**寻路，任何技术不能真的召回她。第十二卷陈渡将她安葬，地点与方式应尊重其生前愿望。 | 不再携行冰舱，不以遗体神化为国家图腾；她的护民选择、人格与种植普通作物的愿望，通过人和制度得以继承。 |
| **江小年（缝针／江楠）** | 白汀救护员入队、职业技能有限但可靠；第四卷确认林霰死亡并诚实记录，不伪造生机。 | 逐卷增长医术、独立性和社会关系；可对陈渡牺牲活人资源的执念提出专业反对。第十一卷后段因主动救人及身份风险被俘（灰窑集旧场景作为可移植草案）；第十二卷获小队营救，并凭医疗专业和团队协作救治重伤陈渡。两人互相接纳，非救命债。 | 担任基层医务组织与伤亡认定制度的重要建立者，不只是领袖伴侣；与陈渡共同承担青隘的现实问题。是否结为伴侣不应替代她自身事业。 |
| **严恪（铁砧）** | 第四卷前线战死。旧义肢休眠信标被发现，但缺乏本次战役通敌证据却遭军部不当定罪；骨灰被封存、后由陈渡夺回。其愿望只是被认可为一个普通士兵。 | 小队保存他真实救人和阵亡记录，并寻找恢复名誉的证据，杜川等人见证其行迹。 | 新青隘设立透明的伤亡认定、复核和家属待遇制度，严恪冤案成为实质制度改革的起点；必要时完成正式平反，而非空喊口号。 |
| **霍山（老霍）** | 三人哨所的工兵父辈；林霰死亡后用现成军用低温设备维修保存遗体；所有改装受材料、能源和物理规律约束。 | 负责设备维修、后勤与工程技术，保留对陈渡执念的情感理解与现实分歧；为第十二卷救援付出合理代价。 | 培养工程师、标准化维修与生产体系，成为真正工业防务建设者，不能凭空造出可碾压世界七强的神器。 |
| **杜衡** | 儒将，克制、守民、不说脏话；在既有军事战略弃守下仍组织撤民、后勤转运，最终重伤掩护余部而殉节，并托孤杜川。**不是自杀。** | 通过遗留民防组织、登记、救援线路、物资库线索，长期影响陈渡与杜川；不以虚构的秘密万能武库推动情节。 | 第十三卷起开始回收其青隘社会关系与制度遗产；陈渡最重要的考验是能否在掌权后比杜衡当年拥有更有效的制度保障。 |
| **杜川（幼松）** | 第四卷为杜衡托孤、被小队救出。 | 由少年后勤与测绘协助者成长为能独立决定并承担失败的组织者；与陈渡形成互相制约而非唯命是从关系。 | 参与军政分工与领导梯队建设，逐步成为重要负责者；重大职务由实际才能、制度与同僚支持产生，而不是血统继位。 |

## 跨卷命运硬边界

1. 第四卷已经写定的三场悲剧顺序**严恪 → 林霰 → 杜衡**不可颠倒；弘毅统帅部战略北撤在陈渡顶撞长官之前已决定，涉事军官个人报复只影响小队任务派遣和信息隐瞒。
2. **林霰第四卷真正死亡，第十二卷正式安葬**。低温装置永远不是低温遗体保存模块，不可复活，不可在第二十卷仍把遗体供奉为青隘政治图腾。
3. **江小年被俘与救援后置第十一至十二卷**，不再写作第五卷末的最终心结解决事件。她的人格与专业能力不应依赖陈渡赋予。
4. **第十二卷只是完成个人救赎**；第十三卷才重返青隘并着手重建；**第十八卷地区第三势力，第20卷世界第八势力**为两层不同的结果。
5. 最后的题眼是「崖边戍卒有了不会轻易抛弃他们的共同体」，而非靠个人战力压倒七大巨头。
