# 《崖边戍卒》人物命运与终局预设

| 人物 | 终局归宿 | 核心意义与情感脉络 |
| :--- | :--- | :--- |
| **陈渡（老渡）** | 拒绝任何强权封赏，永远作为第八势力【崖隅戍治】的守边老戍卒；与江小年结为终身伴侣相守残土 | 青年痛失青梅宁昭封心；第四卷因严恪战死遭诬陷大闹战区指挥部，正值全线战局崩塌，弘毅统帅部为保千万工业核心冷酷沙盘止损决定北调主力，涉事军官借争执强令小队前出断脊岩掩护边民疏散，并隐瞒撤援断桥导致任务A失败，林霰断后战死、青隘侧翼失守、杜衡殉节。陈渡背负滔天负罪感濒临精神崩溃，拒绝承认林霰已死，执意用旧军用低温保存箱随身守护；**以近乎疯魔的执念在全书中期走遍各大势力（锐科、丰壤、荒原遗迹）求索**。第五卷末，他将保存舱托付给杜川，带老霍从宪兵押运队中救回江小年，“总护不住身边人”的自我定罪由此解开，但仍未接受林霰已死；此后逐步接纳生死、建立第八势力【崖隅戍治】，终被江小年舍生忘死救回后放下心防。两人的结合来自彼此选择，不是救命恩情的偿还。 |
| **林霰（灰雀）** | 第四卷侧翼绝命任务A打光最后一弹力竭战死；医学已确凿阵亡，但被深陷负罪心魔的陈渡执意用旧军用低温保存设备封存遗体随身守护 | 苦练凡人神技，暗恋陈渡一生未挑明；虽真正死于任务A断后，但在全书中期被陈渡以低温保存舱随身守护，**成为推动陈渡走遍各大势力、勘破强权虚妄的最核心精神战旗与图腾**；终局冰舱安放在崖隅最高峰青铜静室，化作永恒的守边丰碑。 |
| **江小年（缝针/江楠）** | 陪伴陈渡建立【崖隅戍治】，后期救回濒死重创的陈渡，与他结为终身伴侣相守残土 | 原名江楠，历经家族抄家与被迫充作营妓、趁换防偷换重伤医官身份、退役留白汀再度从军的至暗过往；第五卷末因替逃丁少年止血而暴露身份疑点，被宪兵扣押、遭受羞辱（正文只以衣物破损、扣子缺失和事后反应侧写，不呈现侵害过程）；陈渡救回她时尊重她的边界、不盘问、不索取回报。她仍深守冒名秘密，深知林霰已死，陪同维持遗体低温保存并如实记录参数；后期三天三夜救回陈渡。两人因彼此选择相守，成为崖隅第一女军医长与领袖伴侣。 |
| **严恪（铁砧）** | 第四卷前线阵地战力竭战死；尸审因早年粗钢义肢内的废旧信标遭战区军政处借机避责定性为“锐科敌谍”并示众，骨灰依照军规涉谍物证条例封存，引发陈渡大闹军部掀桌 | 出身苦难家仆，随侍门阀子弟留学被锐科合众吸收为底层线人，回白汀上线被杀断线后从未执行间谍任务，只想清白当个正常人；暗恋江小年因自卑至死未敢言说；其死与军部冲突成为全书悲剧多米诺的第一张骨牌；死后带有封签的骨灰被陈渡在突围前大闹军部抢出带往荒原，立碑于崖隅戍治最高峰，洗雪沉冤，永享功臣英名。 |
| **霍山（老霍）** | 崖隅工业修械总工，见证了陈渡三段沉重情感与小队从荒原据点到第八势力的全部风雨 | 第四卷林霰战死后悲痛觉醒【超凡机械制造】，连夜修复加固旧军用遗体低温保存设备，默默守护陈渡的执念；晚年叼着草烟，守着机械车间，安详终老。 |
| **杜衡** | 迫于形势率青隘合入弘毅领任大区统帅；弘毅北撤主力弃守青隘，侧翼失守后杜衡坚持组织平民疏散与交接救援，最终被围且因伤无法撤离时掩护余部从容殉节 | 原江氏商会从属商贾，商会被抄后聚流民逃兵游击三年建立青隘；受招安后暗中自救遭大势碾碎；青隘失守之际对陈渡战败绝无怪罪，临终电文托孤独子杜川并发出“活下去走自己的路”绝笔；在家园覆灭之际从容殉节，其“守民守边”信条在儿子与陈渡手中化为崖隅战旗。 |
| **杜川（幼松）** | 断崖小队后期执行领队、第八势力【崖隅戍治】前沿总指挥 | 杜衡独子。第四卷突围之夜被陈渡遵遗嘱救出带往荒原；历经各大势力血火磨砺迅速成长，凡人之智，善微地形测绘与后勤运筹；陈渡退居守边老戍卒后，杜川正式接过帅旗出任执行领队，带领千万边民抗衡各大超级霸权，完成两代人护民夙愿的终极接力。 |
