# 《崖边戍卒》战力阶层与战斗行动规则

> **对齐标准**：依据《文风与叙事规范 V1.0》第 3 节（军事与科技）制定。本文件是军事交火、能力判定与胜负推演的唯一权威源。

---

## 1. 战力阶层标准（D - S 级）

- **定性说明**：D–S 层级仅代表该作战单位在**常态无干扰环境下的平均综合战术素养（枪法、反应、战术体能与装备匹配度）**。
- **严禁数据化与面板化**：不存在血条、蓝条或数值碾压。
- **可逆转铁律**：一名 S 级老兵若处于低温失温、外骨骼液压漏油、被两把制式冲锋枪在狭窄转角交叉封锁的状态下，同样会被两名 D 级新兵用破片手雷或散弹轻松击杀。

| 等级 | 典型代表 | 战术水平描述 |
| :--- | :--- | :--- |
| **D 级** | 新兵、未受正规训练的边民民兵 | 会开枪与卧倒，缺乏夜战与协同经验，战况混乱时易恐慌盲射 |
| **C 级** | 常规边防守备兵、废土武装佣兵 | 熟悉单兵火器与基础工事，能执行基础班排战术配合 |
| **B 级** | 青隘老戍卒、正规一线步兵营主力 | 经历过多场流血渗透战，耐力与枪法扎实，具备熟练掩护默契 |
| **A 级** | 陈渡（队长）、各大巨头特战突击老兵 | 顶级战场直觉、精通各类火器与拆弹抢修，单兵极端困境生存能力极强 |
| **S 级** | 极罕见的巨头精锐王牌或老特勤指挥官 | 拥有顶尖改装装备、身经百战的铁血决断力，极少在常规边境露面 |

## 2. 军事行动与战斗推演八大铁律（第 3 节核心）

1. **基础约束**：军事行动严格以已有世界观、军制、编制和技术物理约束为基础，禁止天马行空脱离时代。
2. **战斗五要素闭环**：每一场战斗描写必须清晰交代：
   - **行动目标**（拔点、断后、抢运伤员、侦察）；
   - **环境要素**（风速、温差、能见度、地形高低差、地脉杂波）；
   - **战术限制**（弹药余量、电磁静默、外骨骼电量、伤员拖累）；
   - **执行过程**（压制、穿插、测距、协同切入）；
   - **战后结果**（战利品、真实消耗、阵地归属、伤亡代价）。
3. **动态人数与真实协同**：原核心在各自到场时按已定人物岗位履职（陈渡指挥、林霰观察与精确火力、霍山机械与通信、严恪重装防护、江小年战地救护），但**全书没有固定五人上限或保底**。每次任务依实际在场人数、健康状态、训练技能、装备与指挥权限调整分工；人员可新增、调离、受伤缺席或临时配属，不能自动复制旧成员能力或让一人无代价包揽互斥工作。详见 `01-世界观/小队作战协同与战斗描写规范.md` 第2节。
4. **装备功能锁死**：装备和技术不能临时增加未设定的功能（详见《武器装备与技术.md》）。
5. **轻度超感四项铁律**（详见下文第 3 节）：只能辅助判断或行动，必须遵守能力上限、生理代价及环境失效条件。
6. **技术说明以读者理解当前剧情所需为限**：不写装备说明书，不堆砌无意义口径编号，服务于当下战术理解。
7. **胜负多元因果律**：战斗胜负绝非由主角光环决定，而是由**信息差、单兵能力、临场决策、战前准备、物理环境和合理的不确定性（卡壳、流弹、气候突变）**共同决定。
8. **真实后果延续律**：战斗中的错误判断、人员伤亡、耗材消耗和战术失败，**必须在后续章节留下无法逆转的真实后果**（残疾、伤口感染、弹药告罄、战友情隙），严禁战后“血条自动回满”。

## 3. 特异禀赋（轻度超感）规则与代价

特异禀赋本质是**地脉裂隙低频辐射与特定神经系统长期共振后的病理性/代偿性神经变异**，绝非超自然神力或玄幻异能。

- **法则一：辅助性约束**
  - 常见超感只增强低频、振动等短时感知，并非预知子弹弹道；严恪类少数病例为短暂神经肌肉代偿，但仍受到骨骼、义肢与外骨骼承载极限约束。**严禁隔空杀敌、徒手掀翻整车、肉身挡爆炸或念力控物**。
- **人物特例**：林霰濒死坚持战斗只是短时病理性动作代偿，不能救活已受致死伤者；霍山禀赋只增强材料应力感知与加工判断，不凭空制造材料或能源。
- **法则二：严格上限与疲劳度**
  - 连续使用超过数秒至数十秒，神经突触将产生严重灼痛与感官麻痹，无法连续持续开启。
- **法则三：不可逆生理代价**
  - 强行调用必然伴随生理反噬：毛细血管破裂鼻腔出血、剧烈偏头痛、视力重影失焦、神经痉挛性呕吐。过度使用会直接导致神经永久性坏死。
- **法则四：环境失效机制**
  - 遭遇强电磁干扰脉冲、地脉微震紊乱、深度防毒面具阻隔或强声光震撼弹时，超感直觉将完全紊乱或彻底失效。
