# 极南封印与引导失效｜八项核心设计提案

> 以下新增情节、人物、物理表现、日历和技术条件均为待作者确认的设计提案，不是已锁定设定或已发生正文；作者既有规则与人物命运优先。 来源、恶化根因、与普通超感及栖原巫术同源性仍未知。若作者不接受本模型，16—20卷相应事件必须成组重审，不能把旧结论直接移植。

## 一、八项最小设定

| 项目 | 具体候选规则 | 不可逾越的边界 |
| --- | --- | --- |
| 存在形态 | 暂称“偏移场”。本体不可直接看见；可见的是冰面错台、悬垂物反常偏转、岩层与金属构件的非正常受力。独立机械标尺与电子传感记录可相互校验 | 不呈现人格化影像、声音、语言或意识；不宣称力学原理已知 |
| 活动范围 | 核心异常长期集中在极南一处相互连通的岩冰区域；边界不是墙。历史候选档案记录过沿连续裂带越过外围的现象；是否可传播至其他大陆未知 | 不能瞬移、追人或自动感染所有裂隙；不直接宣布全球毁灭 |
| 基础表现 | 异常可使既有结构局部承受方向不一致的额外应力或出现位移；同一次事件可表现为冰岩开裂、设备变形、人体因机械性外伤受损。可用相邻未受影响参照点区分普通天气、结构老化与异常 | 不控制具体物体、强度、发生时刻或精确作用位置；能量来源及上限不定 |
| 巫术引导 | 第七席受训守护者在既有固定仪式场所，借世代传承的动作、位置与共同仪式尝试改变异常总体偏移方向，使多数既往事件偏向无人岩冰区 | 不给出可复制仪式配方，不决定行为、强度、时刻、结果；其他六席不能施术 |
| 引导失败 | 分为方向未改变、总体方向改变但局部作用不符合预期、观测不足无法分类。近年前两类偏差在可比记录中的比例上升；无可靠精确概率 | 不把记录缺失算作成功或失败；不把异常写成报复或有策略的反制 |
| 封印机制 | 封印为长期维持的组合：第七席在两处既有仪式场所分别承担方向引导与连续守护（并非新建即可生效），无人缓冲区承受偏移；常规道路、栖居、供能、观测和防护使守护者能持续轮换。两场所职责具体仪轨未知，任何工程均不能替代 | 两场所是候选既有地理条件，不意味着锚点能锁住力量；工程不影响力量行为本身 |
| 危机边界 | 旧档记载一次外围逸出使连接冰岩区的天然阻隔受损，并引发沿岸常规灾害；目前一条裂带越过旧缓冲界，威胁两个守护场所的支撑条件及极南居民、相邻航道。撤离普通居民可以减少伤亡，却不能维持守护；放弃所有守护意味着失去唯一已知有限引导手段，扩展范围无可信上界 | “可能扩展”不等于必然全球灭亡；不靠灾难数字或末日倒计时伪装预测能力 |
| 最终胜利 | 保住两处既有仪式场所及受训人员，放弃已危险的主生活保障区，独立备用保障使守护者在新异常期间保持或经确认安全后恢复轮换；连续观测期内无再次发生同类保障单点中断，并留下独立记录和撤离权限 | 只证明当前风险控制方案有限有效，不证明引导成功率恢复、永久可靠、根因解决或力量被消灭 |

## 二、可替代与不可替代

不可替代的是既有仪式场所、能够实施引导的第七席守护者与其传承、必须保持的空间接近条件。两处场所必须各有可用人员与真实接近条件；不能用远程控制、机器人或新巫术补位。可替代的是为人员服务的普通供能、住所、道路、记录、通信、运输和医疗；原主保障区承担这些功能但不是仪式场所。19卷放弃主保障区并临时维持两处场所；20卷验证独立外部保障，旧区不必夺回。失去任一仪式场所不是已知必然末日，而是失去一种现有可验证的守护能力；此为决胜时的具体不可逆风险。

风险窗口仅指现场当前状态满足预先设定的撤离、人员进入或设备运转条件，不是预测下一次异常的时刻。若观测不可用，按未知高风险处理，不能强迫守护者继续。第七席可以决定是否尝试引导，但不能保证结果。

| 席位 | 参加的动机 / 自身成本 | 不可替代的本次任务（是资源与授权的现实约束，不是永恒能力垄断） |
| --- | --- | --- |
| 弘毅 | 极南沿岸运输风险可能推高工业及居民供暖成本；牺牲本土工程排期与设备折损 | 提供既有重型工程班组，在非仪式场所建分散保障设施；不能接管第七席 |
| 锐科 | 维护沿海产业链、避免竞对独占观测成果；承担设备报废、交出受限非个人观测记录的商业成本 | 两种独立监测系统之一、精密传感与维修；电子系统失效时依赖天衡及机械参照 |
| 丰壤 | 保护南向贸易及肥料、粮矿市场，不能牺牲本土种粮；实际粮水材料配额、收入损失 | 提供本次远征所需持续粮水及适用材料，供应量受本土合同和季节限制 |
| 沧溟 | 禁航扩张危及船员、港口及航运生计；船期占用、损船及航运风险 | 闻汐等独立船队运送重件、轮换人员并保留海上退出通路，船权不归陈渡 |
| 天衡 | 旧合作责任、验证异常和临床风险；研究名誉、经费及人员风险 | 独立参照观测、医学与记录复核，不能派正规军；患者自愿 |
| 栖原 | 依赖跨席海贸、不能再次让边民沦为可弃人群；有限资源、领导离任成本 | 陈渡组织山地作业人员、居民撤离和跨席任务接口；江小年独立领导医务协作 |
| 第七席 | 守护者家园、持续职责与传承；公开失败、开放外围、承担高危决策 | 唯一实施巫术方向引导，管理既有场所、决定是否继续仪式，其他席尊重其权责 |

## 四、危机及验证

16卷“冰阶倒置”见证偏移失败，公开旧事故记录；17卷“消失的灯塔”考察航线（灯塔物理错位不是消失术）；18卷“同向异果”在获准观察既有仪式时，整体方向相符但局部岩冰与器件变形不同，机械标尺与电子记录交叉支持；19卷“弃主站、守双坛”放弃危险主保障区保住既有场所和守护者；20卷“第二班守护者”在独立保障上线后经真实新异常、暂停撤离及恢复轮换，再经历一季观察。以此前基线、缺测单独列示、独立双源记录、两场所可用性、人员安全和恢复能力验证；不给小样本编造统计置信度。异常是否恶化仍须持续跨年比较。

具体异常表现和仪式地理待作者确认，需保持现有写实低科幻技术上限；不涉及复活、武器化、意识控制或万能防护。

## 第四轮商业化修订（2026-11-28，规划）

**第四轮事件覆盖旧事件表，不增加新物理法则。** 16卷极南裂冰：连通冰岩区域阶状断面与沿岸装卸设施受损，一次真实航次不能如期靠泊，出现货损和船期损失；不等于异常跨大陆传播。17卷七席远航：测深和旧航标矛盾，找到灯塔迁建旧基座，实地核实历史沿岸灾害。18卷双坛之下：整体方向符合而局部错台、构件变形不同，出现机械伤，年轻守护者选择是否接班。19卷断站守坛：旧主站住房、道路、设备永久失去，保留双坛和人。20卷双坛接力：新异常损坏普通接近设施、电子监测部分失效；分离人员退出、普通保障恢复、后续巫术，七席分别完成已有专业任务，确认当前条件后第七席自主轮换；至少一季后验仅验证本轮单点中断未再发生。尺度、设施、航线、人数、地理及金额待核，候选奇观非作者锁定事实。
