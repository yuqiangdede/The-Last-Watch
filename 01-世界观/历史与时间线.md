# 《崖边戍卒》纪年史与历史大事件

## 1. 纪年系统
- **统一通用历**：公历纪元（2080 - 2145年）。当前正文起始时间为公元 2145 年晚冬（2月18日），第一卷自2月18日至2月23日深夜，约六天；后续卷逐步转入早春。

## 2. 编年大事件表

| 年份 | 历史大事件 | 对当前世界格局与阵营关系的不可逆影响 |
| :--- | :--- | :--- |
| **2084** | **地脉初裂与旧序坍塌** | 全球多处地壳板块深层贯通，地脉裂隙喷发轻度致畸辐射与电磁异变。旧联合国及全球化经济链一夜崩解，强权实体割据自保。 |
| **2095** | **七大超级阵营格局固化** | 弘毅领（重装陆军与集权法统）、锐科合众（技术激进资本寡头）等七强完成地缘划分，开启长达半个世纪的冷战对峙。 |
| **2112-2125** | **第一次裂隙边境热战** | 七大阵营围绕中立地脉缓冲带展开长达13年的血腥拉锯，战线被打烂为犬牙交错的飞地与边境废墟，无人区与流民潮爆发。 |
| **2130** | **中立缓冲带确立与商会自治期** | 为避免全面核战与生态彻底毁灭，各大阵营签署《多边非战缓冲协议》，在弘毅与锐科交界峡谷确立中立非军事减震带。彼时边境秩序由大型边防商会（江氏商会等）出资维系，维持两区商贸与基础治安。 |
| **2136** | **江家商会通敌大案与边境崩解** | 弘毅领以“向锐科走私战略军需”为由跨境抄捕江氏商会，边境基层秩序瞬间坍塌沦为法外死地。江家商会满门遭难，15岁的江楠（后来的江小年）被株连充为弘毅随军营妓；商会下级商人杜衡目睹生灵涂炭，挺身聚拢流民与逃兵，开启长达三年的边境武装游击。 |
| **2137** | **江小年李代桃僵与滞留白汀** | 弘毅南境战线换防混乱之际，营妓管理负责人动恻隐之心，趁重伤濒死女医官无法随军，冒死让江楠顶替其身份成为弘毅军医“江小年”；部队撤出后，江小年因伤残丧失战力被军政部门就地核销退役在白汀，为求生计重操微弱医术。 |
| **2139** | **青隘联防区正式建立** | 杜衡历经三年游击苦战，聚拢两万余难民与八百退伍老兵，正式在峡谷险要依山建垒，确立“青隘联防区”（其12岁独子杜川自幼目睹父辈喋血建城），与白汀中立戍区缔结守望相助盟约，在巨头夹缝中为普通人撑起庇护伞。 |
| **2141** | **黑梁要塞血战与陈渡退役** | 弘毅领精锐A级老兵陈渡（队长）率部死守要塞，青梅女友宁昭在怀中牺牲；陈渡身负重伤（肺部切除三分之一）丧失主力作战价值，遭弘毅高层强制退役驱逐，流落青隘被杜衡收留重拾斗志。 |
| **2143** | **断崖小队重组** | 陈渡接掌青隘联防区最前沿的“断崖小队”，与土生土长的老工匠霍山、猎户遗孤林霰组成前哨三人防守骨干，戍守七折岩险隘。 |
| **2145（第一卷·当下）** | **边隙异动与暗流汇聚** | 公元2145年晚冬，两大超级阵营局部冷战均势破裂，暗中渗透频繁，第一卷《青隘日常 · 孤峰三人》序幕拉开。 |
| **2145（第二卷规划）** | **白汀浩劫与青隘归编** | 弘毅与锐科在边境爆发局部热战波及白汀，断崖小队驰援救下严恪与江小年，白汀覆灭；青隘亦被战火逼入绝境，杜衡迫于大势率青隘整体合编入弘毅领。 |


## 3. 2145年中后期规划事件与信息生效顺序（非已写正文）
- **第三卷第065—066章（春季，具体日期待详写前核对）**：陈渡、林霰等人在丰壤同程述、C-17（阿七）正式相识。后二者早已属于同一个本土劳工反抗网络；程述的锐科境外任务未暴露。陈渡从劳工登记与流言隐约怀疑C-17是克隆人，**不作为科学实证**。林霰在世，禁止写成此时已经寻找复活她。
- **第四卷第125章以后**：林霰真正死亡，陈渡回忆阿七与锐科“同源培育”的传言，才在悲痛中产生复生活人的错误希望。
- **第五卷**：在另一既有势力地区与程述重逢，逐渐发现他和锐科的关系；**第六卷**进一步获得科技档案；**第七卷**回丰壤与阿七重逢，核查克隆能诞生新生命但无法召回原意识。
- **第十一卷**最终技术否定、第十二卷安葬林霰的既定终点不变；第五至二十卷尚未锁定日期和章节号时，不能擅自列精确时间。
