# 第113章 任务卡：医务棚的灯

## 1. 章节基本信息
- **章号**：第113章（卷内第031章）
- **标题**：医务棚的灯
- **卷名**：第四卷《血染残土·孤军叛逃》（第三幕：断脊残火）
- **字数目标**：3000—6000 汉字（硬门禁，严格不低于 3000 字）
- **核心事件**：
  1. 黄昏降临，气温剧降，民间医务棚临时建在山口内侧背风石壁下，点起一盏防风马灯；
  2. 小年为在乱石坡摔脱脚踝的逃难男童复位并用夹板固定，安抚惊恐的边民母子；
  3. 林霰巡查射界归来，主动前往山凹废弃道班房拆取老松木根与枯朽横梁，为医务棚添置取暖柴火，生起铁盆暖火；
  4. 陈渡在隘口手持秒表与账本测算通路容量，测算显示每小时通行率不足二百人，面临夜间路面结冰减速危机；
  5. 马灯与火盆旁，小年与林霰简短交谈：小年盼望回七折岩开一间规整药铺整理医典，林霰渴望回后山修补坍塌的老石水槽并换一把打野兔的旧猎枪看春水融化；陈渡补充回去清理营房排水沟；三人展现具体寻常的生活愿望，确立独立人格与非恋爱羁绊；
  6. 严恪生前手制的小压舌板给小年带来专业勇气，全队凝聚守住隘口让平民生还的坚定意志。

## 2. 场景与人物出场
- **时间**：公元 2145 年初春第五日傍晚（16:30 至 18:30）。
- **地点**：断脊岩隘口内侧背风石窝、临时民间医务棚、隘口测速哨位。
- **出场人物**：
  - **江小年**：专注细致，以有限木料与绷带处理骨折，展现医者冷静与仁心；
  - **林霰**：冷峻少言却行动果决，用体力搬运柴火温暖弱小，吐露平静生活的真实向往；
  - **陈渡**：参谋素养严密，精确计算通行速率与撤离窗口，肩负全队战术重担；
  - **霍山**：在阵地前沿巡视，偶尔送来缴获的破油毡与旧麻绳；
  - **边民母子**：受伤的七岁男童与满面尘土的母亲，提供具体的受护者形象；
  - **严恪（精神在场）**：打磨光滑的小压舌板静躺在药箱角落。

## 3. 去AI味与写作红线
- **严禁全知心理说教与虚假抒情**：绝无“人性的光芒照亮了寒夜”、“微光胜过骄阳”等空洞口号；
- **具体真实的战地与医疗体感**：
  - 骨骼复位时软骨与韧带摩擦的沉闷脆响；
  - 零下十度冷风倒灌进医务棚帆布缝隙发出的哨音；
  - 湿冷松木在生铁炭盆中被火舌炙烤渗出松脂的微甜焦味；
  - 铅笔芯在粗糙牛皮纸上因严寒脆断的物理细节；
- **连续性红线**：
  - 不出现‘这可能是最后一次’式死亡预告；
  - 林霰与小年是战友互助的平视关系，林霰与陈渡是专业互信，绝不滑向俗套恋爱戏码；
  - 边民疏散仍处于早期阶段，两万人大部队尚在大山外侧排队。
- **字数门禁**：正文汉字严格保持在 3200—4500 汉字区间。
