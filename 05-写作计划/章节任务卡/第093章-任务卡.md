# 第093章 写作任务卡：西侧缺口

- 时间地点：2145年春，黄昏残阳消褪、暮色降临，青隘北关西侧一号高地乱石坡、老水闸干渠冲沟拐角。
- 承接前提：接续第092章接应方案。霍山发射两发白磷发烟弹，林霰水塔侦察，陈渡前出掩护，严恪在干渠拐角带补丁钢板后接应。
- 角色岗位与身体限制：
  - 林霰：在水塔利用双目热成像夜视仪指引避弹通路，穿透烟幕发现西侧废弃石板窄冲沟盲区，短卡宾枪精准压制敌追击尖兵；
  - 霍山：六零迫击炮发烟弹打出后，迅速带近防霰弹枪在干渠中段掩护侧翼，左腿伤缠紧；
  - 陈渡：前出至冲沟入口，突击步枪连续点射压制，接应四排撤退；
  - 严恪：在干渠拐弯处带补丁钢板后方担任末端调度，左手握紧支撑角钢，引导演示滑板通道，不冲出开阔地；
  - 曹允：随第二后送队车组赶到，在严恪接引下将第一批重伤员安全转运；
  - 张大成（四排长）：带最后四人护送最后一辆重伤车，遭遇敌机甲一零五毫米榴弹近失弹轰击，推车侧翻，张大成被断木砸伤被困。
- 战术与物资基线：
  - 白磷烟雾遮蔽有效阻滞敌直视视线，但敌车载火炮盲射封锁原定通道，迫使队伍临时改走石板窄冲沟；
  - 曹允在场亲历整个救援与转运过程；
  - 严恪四十八小时医嘱在身，本章尚未突破防线，但目睹战友受困。
- 叙事推进：
  - 【剧情】：白磷烟幕下的惊险转运，第一批伤员成功脱险，但最后一辆运伤车在暮色炮火中侧翻遇险；
  - 【关系】：严恪与曹允的默契配合，陈渡与林霰的高低战术协同；
  - 【悬念】：最后一辆车横在开阔地边缘，机甲炮火再次下落，严恪在钢盾后拉紧了胸前武装带。
- 篇幅与规范：3000—6000汉字。严禁全知剧透；1—2处自暮色硝烟与泥泞碎石长出的新鲜修辞；执行四关机检与八项质检。
