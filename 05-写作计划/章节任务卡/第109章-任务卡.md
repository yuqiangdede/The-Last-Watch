# 第109章 任务卡：第一道石坎

## 1. 章节基本信息
- **章号**：第109章
- **标题**：第一道石坎
- **卷名**：第四卷《血染残土·孤军叛逃》（第三幕：断脊残火）
- **字数目标**：3000—6000 汉字（硬门禁，严禁低于 3000 字）
- **核心事件**：敌八轮装甲车与越野摩托进入八百米坡道；林霰在三号岩嘴首发穿甲弹打碎头车转向桥使之横死路上；老霍果断引爆石梁入口拉发雷区，四块八百斤巨石滚落砸毁二号车并封死道路，形成第一道天然路障“石坎”；陈渡与小年配合步枪点射清理敌摩托步兵，全歼敌前哨车队；但敌后续重迫击炮与工兵分队迅速迫近，防守压力骤增。

## 2. 场景与人物出场
- **时间**：公元 2145 年初春第五日拂晓（05:30 至 07:30）。
- **地点**：断脊岩北侧八百米盘山坡道、石梁北口两米八咽喉、三号岩嘴。
- **人物**：
  - **林霰**：冷冽狙杀，两枪断桥、一枪爆破敌火箭筒手，枪法如神；
  - **霍山**：老辣果决，看准时机压发引信，制造巨石滑坡截断车队；
  - **陈渡**：战术指挥与近程点射掩护，卡宾枪压制攀岩残敌；
  - **江小年**：从容递弹、警戒侧翼，克服枪声恐惧，配合默契；
  - **敌前锋穿插分队**：轻装穿插、气焰嚣张但被瞬间截杀。

## 3. 去AI味与写作红线
