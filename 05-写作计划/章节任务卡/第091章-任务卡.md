# 第091章 写作任务卡：活着回来的士兵

- 时间地点：2145年春，午后，青隘后方南转运兵站登记所、物资发放处。
- 承接前提：接续第090章三条路推演之后。正面炮火间歇性试探，曹允经在防炮洞换药、烘干与修整后，挤压伤缓解，经医务许可归队复岗。
- 角色岗位与身体限制：
  - 曹允：弘毅南境守备兵站第三后送队运医兵，双脚冻伤红肿缓解，怀里收着烘干抚平的家书；去兵站领任务时发现自己被登记为“在途失踪”；
  - 严恪：四十八小时限勤医嘱生效中，**严禁负重搬运**，但可慢速步行；胸前挂着羊毛衬垫，拿着第085章的物资损耗底账陪曹允核验；
  - 兵站经办文书（配角）：被前方溃退撤编的烂账搞得焦头烂额，公事公办但并非恶人，要求凭据说话；
  - 江小年：为曹允出具轻伤可出勤证明与消毒纱布包；
  - 陈渡、林霰、霍山：在前沿缺口调试两门刚调拨的六零迫击炮。
- 核心因果链与制度冲突：
  - 兵站名册上乱划“失踪”以规避补给责任，反映战争撤退前夕后勤制度的崩塌；
  - 严恪用第085章记录的麻绳断裂、夹板编号和两名工兵签名，迫使文书按事实销掉“失踪”印戳，重录“归队在岗”；
  - 严恪帮曹允调担架带，叮嘱战地行走安全，曹允郑重承诺活着运伤员。
- 叙事推进：
  - 【剧情】：曹允身份从“失踪”恢复为“活人”，守住凡人尊严；
  - 【关系】：严恪对普通士兵生命的严肃捍卫，让曹允视其为生死长兄；
  - 【伏笔】：为第094章严恪最后接应曹允、以及第101章曹允据亲见事实作证打下无可动摇的铺垫。
- 篇幅与规范：3000—6000汉字。严禁全知剧透；1—2处自旧账册与印泥气味长出的新鲜修辞；执行四关机检与八项质检。
