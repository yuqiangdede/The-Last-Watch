# 第104章 任务卡：肯盖章的人

## 1. 章节基本信息
- **章号**：第104章
- **标题**：肯盖章的人
- **卷名**：第四卷《故土何归》（第二幕：阵亡无名）
- **字数目标**：3000—6000 汉字（硬门禁，严禁低于 3000 字）
- **核心事件**：杜衡从战区前指闭门军务会议归来，带回“坚守两小时即有装甲旅接防”的书面假通报；杜衡看破弃子骗局，在防空洞目睹白汀遗属惨剧与陈渡手中的蓝色存根联；杜衡顶住战区保卫部门问责压力，以青隘防务最高长官身份，在陈渡抗告报告上郑重签署肯定性评语，并加盖青隘戍卫营关防大印，正式以指挥官人格对抗官僚推诿。

## 2. 场景与人物出场
- **时间**：公元 2145 年初春第四日上午（10:00 至 12:00）。
- **地点**：青隘老营地下指挥所、杜衡简陋签押房。
- **人物**：
  - **杜衡**：温厚、克制、内敛儒将，绝不说脏话粗口、绝不失控咆哮，背负弃子重压与边民生死，铁骨铮铮；
  - **陈渡**：沉着坚韧，持申诉存根联向杜衡汇报走廊次生灾害与体制推诿；
  - **杜川**：疲惫带伤，汇报抢修黑水河浮桥进展与工兵连被抽调的困局。

## 3. 去AI味与写作红线
- **杜衡口吻绝对严控**：绝无脏话粗口、绝不称“老子”、绝不咆哮失态；说话平稳、语速缓慢而重若千钧；
- **真实具体的军制公文细节**：战区防务签批流程、关防印信锁柜、朱砂印泥与防伪铜章磨损痕迹；
- **严禁全知心理说教与口号金句**：杜绝“这是体制的悲哀”、“历史会记住”等虚浮升华，纯以动作、眼神、墨迹与风雪声烘托力量；
- **鲜活修辞**：包含1—2处自旧军用印泥、冻硬毛笔与战地地图生长的生动修辞。
