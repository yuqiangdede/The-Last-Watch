# 第099章 任务卡：江小年的证词

## 1. 章节基本信息
- **章号**：第099章
- **标题**：江小年的证词
- **卷名**：第四卷《故土何归》（第二幕：阵亡无名）
- **字数目标**：3000—6000 汉字（硬门禁，严禁低于 3000 字）
- **核心事件**：江小年接到军政保卫处单独审查传唤；小年因程序恐惧而紧张，林霰协助梳理病历与流水表并指导应对；小年在审讯室顶住女审讯官诱导性提问，用严密详实的医疗记录与秦医官双签证明严恪遵从指令救人事实；拒绝含糊字眼，依法索取盖骑缝章的笔录副本。

## 2. 场景与人物出场
- **时间**：公元 2145 年初春第三日清晨（天阴、冷风卷雪）。
- **地点**：青隘三号防炮洞、战区政治保卫处第二审查室。
- **人物**：
  - **江小年**：年轻卫生兵，从恐惧战栗到凭借医者良知与严密专业据实作证；
  - **林霰**：冷静坚毅，陪伴核账，在关键时刻提供程序保护；
  - **陈渡**：目送出征，给予精神后盾；
  - **顾清（新登场）**：战区军政保卫处女少校审讯官，言语锋利，擅长心理施压与诱导笔录。

## 3. 去AI味与写作红线
- **严禁全知心理议论**：严禁心理活动说教；通过小年手心出汗、指尖发白、深呼吸等生理细节体现紧张；
- **真实具体的战地医疗物证**：敷料消耗账单、凡士林纱布领料单、秦医官双签病历、引流管刻度等写实物证；
- **身份—行为分离原则严格遵守**：小年明确表示“不知道他的过去，只能证明眼前的医疗与救人事实”，不跨界洗白；
- **生动鲜活修辞**：包含1—2处自极寒医疗台与档案室生长的鲜活修辞。
