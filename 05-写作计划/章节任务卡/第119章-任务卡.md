# 第119章 任务卡：没能回来的信号

## 1. 章节基本信息
- **章号**：第119章（卷内第037章）
- **标题**：没能回来的信号
- **卷名**：第四卷《故土何归》（第三幕：断脊残火）
- **字数目标**：3000—6000 汉字（实写 5922 汉字，质量门禁 0 block 0 warn 纯净通过）
- **核心事件**：
  1. 2145年初春第五日清晨（08:03至08:15），断脊岩二号避风石堡遭遇敌第二发迫击炮近距弹着，爆炸波及右前侧风化坡；
  2. 陈渡口述、老霍按键，以短波电台向后方指挥部拍发第二次加密接战报告，补报落弹散布与急需同频校时请求；耳机内除南境转运台大功率载波压制外毫无回音，后方支援谎言与通信封死态势进一步确凿；
  3. 林霰从三号岩嘴观测到敌迫击炮重新校核仰角，且四辆轮式步战车横移斜指西梁；敌军两辆卡车于排水沟旁卸载步兵，八名雪地白斗篷沿西侧老羊道展开穿插渗透，意图绕向石堡后方包抄断坎与撤民通道；
  4. 老霍取出自制微型短距地波脉冲发射器，利用破电台线圈与天线铜丝，绕过战区电磁封锁，成功连通鬼见愁断坎对岸曹允民兵排的手摇磁石野战电话；陈渡下达三道关键指令：通报无后方援军、黑风沟入口设障阻绝回头、行动不便者全部改走背阴险坡单人小径；
  5. 陈渡重组防御阵型，在战术挂图上将守备范围全面收缩至二号石堡与三号岩嘴两点，并标定南向碎石斜坡为底线撤离通道；
  6. 敌第三发迫击炮杀伤覆盖弹砸在石堡前三十米，冲击波掀翻浮土；陈渡核准撤离判据，命江小年清理岩洞应急通道，命老霍备好独头霰弹地雷机关，全队坚决留在正面继续争取宝贵的撤离时间。

## 2. 场景与人物出场
- **时间**：公元 2145 年初春第五日清晨（08:03 至 08:15）。
- **地点**：断脊岩二号避风石堡内部、三号岩嘴观察哨位、石堡后侧斜下方天然石洞、远方黄土梁迫击炮与步战车阵位。
- **人物**：
  - **陈渡**：沉着果决的阵地主心骨；冷静执行规范拍发取证，快速判定敌穿插意图并收缩守备线；坚守掩护老弱的底线，为撤退队伍争取每一分钟；
  - **霍山（老霍）**：老工兵经验丰富，熟练操作短波电台拍发密电，并用自制地波脉冲发射器在绝境中接通对岸曹允；利用报废零件与加重独头弹构筑门框近防地雷；
  - **林霰**：高位观察冷静敏锐，从敌步战车炮管朝向与迫击炮仰角变化中精准预判敌步兵老羊道迂回，提供关键情报；
  - **江小年**：留守石堡后侧岩洞，恪守医护职责，听到撤离预警后利落搬开挡风石清出单人逃生窄缝；
  - **曹允（通信中继/间接出场）**：在鬼见愁断坎对岸守候手摇野战电话，接收三道避险指令并通报最后一批担架已过梁。
