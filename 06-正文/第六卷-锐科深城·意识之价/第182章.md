# 第001章 门里的人

铅灰色的浓云像一层挂满油垢的旧帆布，压在荒原北缘的地平线上。

“山獾”号履带车的减速箱在冰冷的泥浆里发出粗粝的齿轮咬合声。履带板卷起混杂着暗红铁砂与黑冻土的泥块，甩在挡泥钢板上，咚咚作响。车头前方两百米外，由六道角铁拒马和双层刺网拉起的隔离带，将冻土荒原与庞大的灰黑穹顶基座切成两个世界。

第七综合安检关卡。

门楼是战前的高标号防爆水泥浇筑的，表面布满风化凹坑与弹药修补痕迹。几盏防雾高压水银灯在寒风中滋滋作响，投下惨白而死寂的硬光，照亮了关卡上方褪色的锐科外勤齿轮徽标。

霍山双手死死把着方向盘，大拇指在生锈的铁圈上狠搓了两下，踩下离合，拉起角铁重新焊过的驻车制动杆。

制动蹄铁发出刺耳的声响，山獾号震颤了一下，停在标有“外来车辆受审停止线”的斑马线前。

“到了。”霍山吐了一口带土腥味的唾沫，“这帮狗日的探照灯，晃得人眼珠子生疼。”

副驾驶席上，陈渡缓缓坐直身体。

受损的右肺在冷风里发出一阵极细微的杂音，胸腔深处泛起钝痛，顺着肋间神经蔓延到后背。他没用手揉，慢慢吐出一口浑浊的热气。热气在挡风玻璃上凝成薄霜，迅速冻硬。

后厢铁门被推开一条缝，杜川夹着磨得发亮的黑色公文包钻了出来。他的铁丝眼镜片上蒙着水汽，鼻尖冻得发红。

“回函在最上层。”杜川声音压得很低，语调平稳，“电文原件、阿七签署的备忘录副联、青隘守备营的旧军籍档案复印件。另外，车里剩下的四块银元，两块压在夹层，两块带在身上备用。”

车斗上方，程述翻身跳下踏板。他身上的旧军皮袄裹得很紧，左臂依然用灰黑色的战术吊带吊在胸前，右手揣在口袋里，眼神警惕地扫视着关卡上方的暗哨与工事射孔。

江小年提着帆布药箱下车，白大褂穿在棉袄外面。下车前，她回头看了一眼车厢正中央被八道尼龙带固定的灰色金属长箱。箱体侧面的温控仪表微弱跳动着：“-1.8℃”。

“冷机电瓶还有最后两格。”江小年走到陈渡身侧，声音紧绷，“停车以后靠副电瓶撑不过六个小时，得尽快接上地面的工业电。”

陈渡点了点头，踩着挂满冻泥的履带踏板跳下车。

五个人落在碎石冻土上，彼此严格保持着三步左右的策应距离。

关卡铁丝网后方，两个身穿深灰防化迷彩、外罩防弹背心的锐科安检员端着半自动卡宾枪走出来。枪口斜指地面四十度，保险处于待击位置。

“站住。外来车辆熄火，人员脱帽，退后三步，双手放在视线以内。”领头的安检员隔着呼吸阀说道。

陈渡停下脚步，解开领口风纪扣，将双手从大衣口袋里拿出来，掌心朝前。

杜川上前一步，递过折好的薄纸。

“弘毅领原青隘防区人员，应聘锐科联合防卫部特种外勤保障岗位。”杜川沉着道，“这是今日凌晨收到的受审电文回函，临时序列号：SEC-PEND-7709。”

安检员接过电报纸，用掌上终端扫过右下角的校验码。

滴的一声轻响。

终端跳出绿色的系统提示。安检员看了陈渡一眼：“陈渡？”

“是。”

“回函有效。但这只证明应聘申请进入初审序列，不等于录用，不等于通行许可，更不代表能进入穹顶主城。接受正式面谈前，所有人必须在第七关卡外围候审棚接受生物检疫、身份核验和装备暂存。”

“可以。”陈渡回答。

“车上有什么？”另一名安检员走到山獾号侧面，敲了敲履带板。

“随车修车工具一套，自制轻型防弹装甲，两挺拆卸的车载重机枪，个人防身轻武器三支，弹药若干。”杜川递出清单，“这是物资自报清单。另外，车厢内有原青隘守备营营长严恪的骨灰盒，以及一台改装的遗体低温保存装置。”

听到“骨灰盒”和“遗体低温保存装置”，安检员眉头微皱，拿起对讲机呼叫。

几分钟后，铁门滑开。一名穿深蓝制服、胸挂“第七安检站身份核验经办”金属胸牌的中年男人带着两名勤务兵走出来。男人手里拿着厚登记册。

“我是经办员苏文。”男人打量着五人，“应聘的是你一个人，这四位是……”

“我的同伴。”陈渡说。

苏文翻开登记册：“按照条例，如果你以主应聘人身份在保证书上签字，将他们登记为你个人的‘随行附属劳务人员’或‘家属’，审查流程可以合并走简易通道。五个人共用一个候审编号，行动由你全权作保。”

陈渡抬手挡住欲言的霍山：“不合并。他们不是我的下属，也不是家属。每个人独立受审，独立核验身份，各自拿各自的居留凭据。”

苏文抬起头：“你想清楚。分开登记，每个人单独过背调、单独核定活动区域。如果有人底子不干净，直接限区扣留，甚至连累你明天的面谈。合并登记的话，只要你明天通过，他们暂时能跟着你在外围活动。”

“想清楚了。”陈渡平静道，“分开登记，每个人对自己负责。”

苏文摇摇头：“行，那就逐个来。”

五人被带入一侧的铁皮申报室。室内弥漫着消毒水与柴油暖风机的焦糊味。

铁皮桌前，苏文拉过键盘：“第一个，陈渡。”

陈渡按下拇指指纹。屏幕上数据跳动。

“陈渡，原弘毅领青隘守备营少校副营长，特种突击与机件维修专业。未正常退役，关联断脊岩突围事件，通缉状态已于上月转入‘非主动敌对溃散’类目。右肺重度挫裂伤伴纤维化。无恶性传染病史。”苏文打印出硬纸卡片，“发给临时候审通行证A类，编号AP-06-001。活动范围：第七关卡生活区、外围维修工棚、明日面试场地。禁止进入内层穹顶与科研核心区。”

“第二个，杜川。”

杜川上前按指纹。

“原青隘守备营后勤参谋，无重大通缉前科。发给临时候审凭证B类，编号AP-06-002。范围：候审生活区、物资保管处。”

“第三个，江小年。”

小年递交卫生员证明。

“原救护站助理卫生员。发给临时医疗随行凭证C类，编号AP-06-003。范围：候审生活区、应急医疗站外围。”

“第四个，霍山。”

霍山把沾着机油的大手在裤腿上擦干后按上玻璃窗。

“原弘毅重型装甲车修造技工。发给临时技术滞留凭证D类，编号AP-06-004。范围：受限维修车间、设备停放棚。”

轮到第五个人。

程述走上前，伸出右手按在采集窗上。

读卡器骤然发出刺耳的蜂鸣，屏幕上弹出黄色警告框：

【系统冲突：检测到失效身份序列代码。原锐科境外派遣司二处第三巡视组，雇员代码：REC-EXP-1109。人员状态：已除名（缺勤离岗超过七年，未经最终清算）。】

空气瞬间紧绷。

苏文盯着程述：“程述？当年在外派司经办物资交接的程述？”

程述嘴角扯了扯：“是我。七年没见，锐科数据库倒是灵光了一点。”

苏文深吸一口气，看向陈渡：“我说过什么来着？他身上的代码有冲突。外派司当年撤编有一批账没结清，他不能走普通候审流程。”

陈渡上前一步：“他有生效的正式逮捕令吗？”

苏文调出深层档案，屏幕上只有一行黄色批注：*待查证历史经办账目，建议限制出境并补充调取归档副联。*

“没有正式逮捕令。”苏文公事公办道，“但有‘限区候审追索提示’。程述，你不能去普通通铺，必须进东侧待核查人员隔离滞留室，没有安全主管签署回执不得外出。”

苏文抽出一张红斜杠的硬纸凭证：“签了它。等外派司当年的档案库回函。要是查出亏空军资的硬证据，直接转交法务。”

霍山急道：“老程手臂还吊着……”

程述右手按住霍山的肩膀，抓起桌上的笔签下名字：“规矩就是规矩。七年前走的时候我就知道有这么一天。行，我就在东棚待着。”

他转头对陈渡低声道：“别管我，顾好车里的东西。”

程述被勤务兵带往后门。陈渡看着他的背影，胸口微起伏，没有阻拦。

“现在算装备和物资。”苏文翻开新页，“车载机枪、穿甲弹药入库暂存，发给存根副联，离开时凭副联取回。骨灰盒呢？”

杜川从车里抱出贴着火漆铅封的黑胡桃木箱。

苏文仔细核对铅封与火漆完整后盖章：“骨灰盒存放在恒温寄存库3号柜，凭票领取，每日保管费五角锐科辅币。离开时结清。”

杜川核对日期、柜号与经手人签名后收好副联。

“最后一样。”陈渡开口，“遗体低温保存模块。”

苏文看了一眼清单：“野战低温生物样本储存单元·丙型。包含一具亚低温状态遗体。只能停在关卡外围的重型设备检修棚，接工业动力电。但电不是白给的。”

“多少钱？”杜川问。

“设备棚按工业用电计费。先交两块弘毅银元，接四十八小时；初装与接地保护押金另收两块。一共先交四块银元。”

听到这个数字，霍山脸颊抽动了一下。四块银元是他们全部的现钱。

“能不能通融？”霍山哑声道，“我们自己带了电缆，自己接地线……”

“这是条例。”苏文合上册子，“变压器是高压滤波的，烧了配电盘谁赔？不交押金不能接网，你们可以继续用柴油发电机。”

柴油机撑不过两个小时了。

陈渡转头对杜川道：“拿钱。”

杜川掏出帆布袋，解开绳扣，将四枚边缘磨损严重的旧银元一枚枚摆在铁皮桌上。

当啷。当啷。当啷。当啷。

苏文验过成色，撕下一张盖有椭圆章的绿色三联票据递给陈渡。

“供电从今晚八点算起，截止后天晚上八点，四十八小时。如果后天晚上八点前没续费，系统自动切断供电。”

陈渡接过票据，收拢在掌心。

四块银元，买了四十八小时。

勤务兵开始收拾桌面，陈渡站在桌前，却没有挪动脚步。

苏文皱眉：“还有事？”

陈渡看着他，声音很轻，但字字沉缓：

“遗体保存模块里的人叫林霰。在断脊岩牺牲。她的身体组织在低温下完整保存，没有发生不可逆腐烂。”

苏文愣了一下。

“我想问问。”陈渡直视着他，“在锐科，有没有合法的医学程序，能让她……本人回来？”

屋里瞬间安静下来。江小年指尖颤了颤，低下头咬紧嘴唇。

苏文看着陈渡冷峻的面容，沉默了数秒。他眼里的麻木化作一丝混杂同情与冷淡的神色，抽出一张浅灰便签，随手写下一个号码推过去。

便签抬头印着：*锐科联合防卫部附属第三临床中心·遗体修复与生物机能咨询处*。

“这是普通民用医学咨询的排号凭据，在辅助医疗站。”苏文淡淡道，“但我按职责告诉你三点：”

“第一，这个窗口只负责创伤组织修复、低温细胞活性维持等常规临床问题。死人就是死人，不提供‘召回死者意识’的服务，正规机构也没人敢承诺。”

“第二，锐科三所核心实验室在地下深处，那是军事禁区。凭你手里的A类卡，连内层围墙都通不过，别想接触核心研究。”

“第三，明天好好去面试。当上外勤防卫员，津贴或许够交电费。面试要是没过，后天晚上八点带着箱子回荒原。”

苏文披上大衣起身：“带他们去设备棚。”

陈渡拿起便签，折好，放进贴胸的内侧口袋。他脸上没有怒意，也没有失望。在这片土地上，只要门还没彻底关死，只要还有一条前行的缝隙，他就不会停下。

十分钟后，重型设备检修棚。

机库用波纹钢板与角铁搭建，停着推土机与工程车，空气里弥漫着重油味与金属氧割后的焦臭。

山獾号倒车停在“外部临时动力接入桩·07号”旁。

电工拖着黑色橡胶电缆走来：“接头拿出来！”

霍山抢先上车取出改装接头，咬着螺丝刀用万用表反复核验输入电压、相序与接地阻抗：“零地电压不能超三伏！变频板烧了老子找你们算账！”

“行了，荒原土炮宝贝破铁皮。”电工啐了一口，但在霍山通红的双眼盯视下，还是将接地螺栓拧紧。

咔哒。配电箱高压开关合上。

电缆微微震颤，发出低沉平稳的嗡鸣。

车厢内，冷机顶部的绿灯亮起，温控屏浮现冷白背光。活塞平稳往复，将冷媒压入管路。

江小年盯着屏幕上的数值从“-1.8℃”缓慢滑向“-2.0℃”，舒了一口气靠在铁板上：“接上了，电很稳。”

陈渡站在机库穿堂风里，看了一眼钢梁缝隙外惨淡的夜空。探照灯在浓云下扫荡，像是一只冰冷的眼睛。

程述在东面隔离棚候审。杜川在登记台清点空桶与存根。霍山抱着扳手盘腿坐在履带旁守前半夜。

四块银元花尽了。

明天早晨八点，防卫部工棚里有一场背调面试在等着他。

陈渡摸了摸胸口的便签，拉上防寒帘，将刺骨的冷风关在了门外。
