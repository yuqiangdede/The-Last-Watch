# 人物档案：杜川（代号：幼松 / 智谋型核心成员 / 后期领队）

## 索引速查字段（摘要）
- **所属阵营/身份**：杜衡之子、青隘年轻见习参谋；第四卷突围后正式随断崖小队行动；第五卷主角团智谋型核心成员
- **核心定位**：后勤保障为专业根基，心理战为重要强项，电子设备为长期个人专长的智谋型主角团成员
- **显性性格**：谦逊稳重、沉着清澈、愿担责任；初期实战搏杀经验欠缺，大局观强
- **能力特长**：后勤计划与物资调配、谈判与心理博弈、电子技术与信息分析、微地形测绘与步炮推演；后期经磨炼承担前线指挥


## 1. 基础信息
- **姓名/战术代号**：杜川 / 小名“川儿”，后期战术代号“幼松”
- **性别**：男
- **首次登场**：第一卷/青隘城寨司令部（作为年轻见习参谋出场）；第三卷随断崖小队至中立丰壤口岸，任临时交涉助手（未参加敌后破袭，第073—074章协助核实青隘消息，后留在商路接收点）；第四卷突围时被陈渡带走正式入队；第五至十二卷随队历练；第十三至二十卷参与青隘重建并逐步承担军政组织工作
- **角色定位**：主角（断崖小队群像核心主角 / 智谋型核心成员 / 杜衡之子 / 小队后期执行领队）
- **生理年龄**：出场时18岁（见习参谋）；第四卷突围仍约18岁（若剧情历时不足一年，不得无故写成20岁）；第十三至二十卷的年龄须随实际时间线自然增长，终局年龄待定
- **出身背景**：青隘总防长杜衡的独生子。祖上为白汀与青隘边境商贾（江小年家族商会下级商人）；自幼目睹父亲聚拢流民打三年游击建立青隘联防区，耳濡目染“在巨头铁蹄下守护普通人”的戍边信念。
- **教育经历（天衡留学·正式补充）**：杜川此前曾通过严格入学审查，按**正规留学**途径进入位于与外界隔绝海岛上的【天衡共同体】深造。天衡是世界级学术及**医学中心**，没有军事自卫能力但对外来人员审核极严。正规求访入岛的常规途径仅为严格筛选的留学；杜川本人不能为陈渡免除资质、身份和许可审查。
  - **主修：后勤保障。** 系统接受后勤组织、物资调配、运输与供应链、仓储、应急保障、资源统筹等专业训练。这是他的学科主干和最扎实的系统能力来源。
  - **辅修：心理学。** 学习认知、行为、社会与群体心理等方向，尤其擅长将心理学知识用于谈判、动机分析、信息影响与心理博弈。该学习背景是他心理战能力的理论基础；真正成为高手还应在人物既有经历或后续事件中展示长期实践积累。
  - **个人爱好：电子技术。** 非正式主修专业，而是长期自学和实践积累的专长。熟悉电子电路、通信设备、传感器、嵌入式与控制设备、基础软硬件故障排查和数据处理。可在项目世界观允许的技术条件内表现出高水平的电子设备运用能力。
- **核心定位与团队职责**：
  - **后勤保障：** 能在资源有限时编排运输、补给、维护优先级和应急方案；推动队伍从零散求生走向有计划的持续行动。
  - **心理战：** 善于识别对手的利益、动机与判断偏差；组织谈判、推演对方反应、识别信息诱导，并在行动前提供心理与信息层面的方案。
  - **电子设备：** 熟练使用、分析和维护通信、监测与控制相关设备，能与工程技术人员协作处理电子问题；具体成效受设备条件、技术壁垒和时间所限。
  - **团队职责：** 后勤计划、心理博弈、电子技术与信息分析。可以参与战斗方案制定，但不取代陈渡的军事指挥。
- **外貌特征**：身形挺拔如年轻白杨，眉眼肖似其父杜衡，眼神清澈而坚定；常年身穿杜衡留下的改小版旧军装，腰间佩戴其父传下的青铜戍卒短刀；随身挂着军用作战地图包与便携战术终端。

## 2. 人生经历与蜕变轨迹
- **幼承庭训、天衡留学与青隘少年**：
  - 自幼生活在青隘大峡谷的水泥要塞与边民集市中，极受两万边民爱戴，但从未有官宦子弟的骄纵之气；
  - 曾前往天衡共同体系统留学，主修后勤保障、辅修心理学，并长期钻研电子技术，积累了扎实的现代系统性知识体系；归国后在青隘担任年轻见习参谋；
  - 极其崇拜父亲杜衡以及陈渡、老霍、林霰等一线断崖戍卒老兵，闲暇时常跟着老霍学修车、向林霰请教弹道；
- **丰壤随行与第一次“被送出去”（第三卷）**：
  - 既有起点：第029章带辎重和担架接应，第033章参与粮仓核算，第035—039章参与相关文书与整编；陈渡已见其能力。第三卷增长点是将天衡所学及青隘既有经验用于陌生的外部担保、贸易规则与利益冲突，允许误判并承担损失。
  - 第三卷第054章，杜衡在弘毅的破袭任务上争来“丰壤商路与购粮评估”附项，把杜川以见习参谋、交涉助手的身份列入随行；名义是学商路，实际是父亲想给杜家留一个不在青隘的人；
  - 第059章出征前夜，杜衡把一枚旧商号铜扣和两句联络暗语交给他，说“封线断了就留在丰壤，别回来”；杜川不接这句话，只问老营疏散名单谁核、父亲的腿谁盯着换药；
  - 第061—068章，他负责通关文书、粮价与关税询价、商号联络和测绘补点；第065章第一次试探丰壤能否接收整批难民，只得到“有合同的劳工可以进，家属不带”的硬边；第068章按约定留在丰壤一侧的商号落脚点，不参加破袭；
  - 第073—074章，他从商路消息得知青隘接火并协助核实；丰壤阶段报告尝试经商路捎出，送达未确认。第076章他留在关内商路接收点，未随五人回援；截至第082章正文，返青隘的时间、路线及材料交接均未交代，第四卷须补足可信行动链；
  - 第135—136章，杜衡第二次、也是最后一次把他往外送；这一次他不再争，只要求把最后一份路线记录带出去。第三卷的这次随行是他第一次真正接触外部贸易与“丰壤不是避难所”的现实，也是第五至七卷交涉能力的起点，不是提前成为谈判天才。
- **绝命托孤与火海突围（第四卷）**：
  - 第四卷青隘战区失守、林霰战死、杜衡深知青隘早成弃子，在救民撤离中重伤被围、寡不敌众、最终自尽殉国前，经电台托付陈渡寻找杜川、带活着的人离开；杜川与陈渡当时均未亲见最后一幕
  - 突围之夜，陈渡冒死冲入宪兵包围圈将杜川救出，与老霍、小年、严恪骨灰、林霰低温遗体保存设备一同杀穿铁幕突入荒原；
  - 亲历家园覆灭、后来获悉父亲自尽殉国的巨变，杜川没有被悲痛击垮，而是咬碎牙齿迅速成长，在血与火中完成了从“被保护的孩子”到“钢铁战士”的惨烈成年礼。
- **跨势力求索与磨砺拔节（第五至十二卷）**：
  - 第五卷随队出逃后正式成为主角团智谋型骨干，天衡留学所掌握的后勤、心理博弈与电子技术开始全面发挥关键作用；
  - 第五卷建议呈现（剧情预留）：
    - 用留学和专业训练解释对物资计划、运输与供应风险的敏感度；
    - 在谈判中利用心理学和具体情报识别对方真实诉求，不写成神奇读心术；
    - 在通信或电子监测出现问题时动手排查，展示兴趣带来的实际专业水准；
    - 天衡留学经历允许自然引入旧同学、教师或同行等人脉，但不得无铺垫直接赋予其高层政治资源；
  - 第五卷随陈渡返丰壤找阿七，第六卷支持其以受限身份进入锐科调查复制人；**锐科克隆路线证伪后，杜川才向陈渡明确介绍天衡海岛医学中心、严格留学入岛条件**，并据所学评估从沧溟寻找特殊海运线路的现实成本；第八至十一卷陪同查证天衡医学。陈渡由于深陷林霰遗体保存与复生执念、且受地脉反噬剧烈咳血，具体的后勤统筹、物资计划、心理与信息风险评估均由杜川主动挑起；
  - 杜川敬重陈渡如师如父，默默替陈渡分担全队的生存压力，深受老霍与江小年的倚重。
- **后期领队担当与第八势力支柱（第十三至二十卷）**：
  - 第十三至二十卷返乡重建时，杜川从测绘、后勤和战术组织岗位起步，经历失败和训练，逐步成为新青隘的前沿指挥骨干；如获得联防总指挥职务，必须来自实际功绩和适当组织程序，而不是血统世袭；
  - 他继承父亲杜衡的遗志，以“寸土寸血，守民守家”为纲领，配合老霍的大炮、江小年的军医所与陈渡的精神威望，带领万千荒原遗民打退各大巨头围剿，让青隘的火种在崖隅真正燎原！

## 3. 战斗能力、专业定位与角色边界
- **核心战术职能**：智谋型主角团核心成员，后期前线指挥官兼战术参谋。团队职责涵盖后勤计划、心理博弈、电子技术与信息分析。可以参与战斗方案制定，但不取代陈渡的军事指挥。
- **四大专业定位与特长**：
  - **后勤保障（专业根基）**：天衡留学主修。能在资源有限时编排运输、补给、维护优先级和应急方案；推动队伍从零散求生走向有计划的持续行动；精通微地形测绘、步炮协同推演，善于后勤推演与组织协调。能力来自专业系统训练和真实失败后的成长，而非“管理血统”。
  - **心理战（重要强项）**：天衡留学辅修。善于识别对手的利益、动机与判断偏差；组织谈判、推演对方反应、识别信息诱导，并在行动前提供心理与信息层面的应对方案。
  - **电子设备（长期个人专长）**：长期自学与实践积累。熟练使用、分析和维护通信、监测与控制相关设备，能与工程技术人员协作处理电子电路、传感器、嵌入式与控制设备、软硬件故障排查和数据处理。
  - **单兵作战**：熟练操作7.62mm战术突击步枪与自卫手枪，枪法沉稳扎实，能在混战中精准冷静地下达撤退或穿插指令；但不是突击手，不因擅长心理战和电子技术就具备顶级正面交火能力。
  - **无超凡禀赋，纯凡人之智**：杜川没有任何地脉超感或异能，但他以凡人之躯的严密计算、坚韧心智与护民热血，逐步成为能够独立负责具体事务的组织者。
- **角色边界（硬性红线）**：
  - 不能“读心”：心理判断必须建立在可观察事实和可验证情报上，也会误判。
  - 不能轻易攻破任何电子系统：对陌生系统、加密系统和先进设备，需要工具、时间和信息支持。
  - 不是突然转型的突击手：不因擅长心理战和电子技术就具备顶级正面作战能力。
  - 技能必须在后续具体情节中通过过程与代价体现，避免用旁白宣称“高手”。
- **与其他角色的明确分工**：
  - **杜川与霍山：** 杜川偏向通信、电子控制、数据和供应组织；霍山偏向机械工程、供电、装置改造与实体设备维修。两人互补，不互相夺职能。
  - **杜川与程述：** 杜川偏心理判断、信息筹划、电子分析；程述偏地下组织经验、现场潜伏、非常规作战和人际网络。两人可形成智谋与行动组合。
  - **杜川与陈渡：** 杜川提供后勤、信息和心理风险判断；陈渡负责军事决策和团队总体指挥。

## 4. 人格与情感底层逻辑
- **外显性格**：沉稳少言、谦逊懂礼、遇事极有担当；对待伤员和流民充满同理心与温度，面对强权军阀则寸步不让。
- **核心动机**：“我爹为了身后两万老百姓死在青隘，老渡叔用命把我从死人堆里刨出来。这面旗，老一辈立起来，我们这代人就算拿骨头填，也必须扛到底！”
- **与核心成员关系**：
  - **对陈渡**：视陈渡为灵魂导师与生死长兄，在陈渡疯魔求索期充当最坚定的现实锚点；陈渡负责总体军事指挥，杜川提供后勤、信息与心理风险支持；
  - **对霍山**：把老霍当亲爷爷，任由老霍吹胡子瞪眼敲打，老霍嘴上骂“小兔崽子”，手搓新枪械总是第一个让杜川装上试射；分工上杜川管通信与电子控制，老霍管机械与动力供电；
  - **对程述**：第五卷程述正式入队后，杜川的后勤计划、心理分析、电子数据与程述的地下网络、现场潜伏、非常规作战形成极具默契的智谋与行动组合；
  - **对江小年**：知晓父辈与江家的旧商会渊源，敬重小年的医者仁心，在队伍里如姐弟般互相扶持。

## 5. 禁止偏离清单
- ❌ 绝对禁止：写成依仗父荫、无脑冲动、争权夺利的二世祖。
- ❌ 绝对禁止：在陈渡陷入心魔时冷嘲热讽或背叛队伍。
- ❌ 绝对禁止：对苦难平民展现出高高在上的贵族优越感。
- ❌ 绝对禁止：写成能随意窥探人心意图的“神奇读心术”或无所不能的“超级黑客”，电子技术和心理判断必须受设备条件、加密壁垒、时间与情报制约。
- ❌ 绝对禁止：在天衡留学背景下无铺垫直接赋予其高层政治资源或调动世界大势的万能权限。
- ❌ 绝对禁止：在第三卷把他写成正式战斗成员、少年谈判天才或突然能独立处理整批难民；他只能做商路询价、文书、测绘、联络记录，破袭段留在丰壤一侧，并在第076章留在关内；返防过程待第四卷交代。
- ❌ 绝对禁止：把第三卷的丰壤联络写成已谈成的庇护协议或即时救援通道；丰壤只回以有限贸易与合同劳工，不接整批难民。
