# 辅助角色小传归档说明

- **全局约束**：遵守仓库根目录 `AGENTS.md` 的“人物二次出现强制建档规则”。
- **建档门槛**：同一可辨认人物跨至少两章，或在两个独立场景／事件出现，即必须独立建档；重要线索人物、核心牺牲者及主角的重要旧人首次出现就要建档。
- **未命名角色**：可以身份或稳定称呼建档，姓名、军衔、经历不明的内容标“未确认”，不得脑补。
- **命名规范**：`第XXX章-角色名.md`，如 `第001章-边民老猎户.md`（以首次提及章归档，三位章节编号）。
- **内容至少覆盖**：身份、首次提及与实际登场、关系、已见事实、性格和口吻证据、命运状态、禁写边界、来源章节。
- **索引同步**：小传新增与变更须同步 `02-人物/人物总表.md`；`00-人物档案.md` 为只读编译视图。
- **审查顺序**：写前检查任务卡角色；写后扫描新角色及别称，对照已建档名单复核；达到门槛未建档视为质检不通过。
