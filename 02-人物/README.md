# 人物档案目录规则

本目录以**主角／配角／辅助角色**分层；**配角与辅助角色继续按首次正式登场时的所属势力建子目录**。标准路径：

- `主角/角色名.md`（现有主角目录保持不变）
- `配角/初始所属势力/角色名.md`
- `辅助角色/初始所属势力/第XXX章-角色名.md`
- `辅助角色/初始所属势力/第一卷插章005-角色名.md`（插章优先用卷次、插入编号与角色名标明首次出场）
- `辅助角色/初始阵营未确认/`（证据不足时保守暂存，不伪造阵营）

**初始所属势力**指第一次正式登场时所属的组织／阵营，不是籍贯，也不是人物早年的服役单位。之后转投、征编、叛逃、政治身份变化只改小传的动态履历，不移动档案目录；若只是发现初始归属判断有误，才更正目录并修复所有引用。

插章与编号正文**一视同仁**：有名、有稳定称谓、多独立场景复现、持续影响情节的职能人员（即使匿名）都必须建独立小传；纯一次性无身份群演可豁免。规划时在概要、约500字简写和任务卡中列出“参演人物→所属势力→小传路径→是否待建”，未补齐不得进行正式详写；写后再次审计新增人物。

同一人物**只保留一份权威小传**，首次登场前后变化在同一文件内记录，`02-人物/人物总表.md`提供统一索引。`00-人物档案.md`是只读编译产物。
