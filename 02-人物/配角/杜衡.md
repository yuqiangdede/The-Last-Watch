# 人物档案：杜衡（青隘联防区总指挥官）

## 索引速查字段（摘要）
- **所属阵营/身份**：青隘联防区总防长；整编后任弘毅青隘防区地方防务负责人
- **显性性格**：温厚审慎、明辨是非，临阵果决且敢担责；儒将，不辱骂他人
- **能力特长**：民防组织、粮道筹措、撤民指挥和多方协调；无弘毅主力自主调度权


## 1. 基础信息
- **姓名/职务**：杜衡 / 原青隘联防区总防长；后任弘毅领青隘防区整编防务负责人（辖青隘地方守备，受战区统帅部节制，无主力装甲旅自主调度权）
- **首次登场**：第一卷/青隘指挥部
- **角色定位**：核心配角（父辈领袖 / 阵营支柱 / 精神导师）
- **生理年龄**：58 岁
- **出身背景**：**白汀与青隘边境本土商贾家庭**。早年曾是江小年（江楠）家族大型商会旗下的下级/从属商人；在两大势力未彻底撕破脸前，当地秩序主要依靠大商会维系，杜衡常年辗转在弘毅与锐科两大霸权夹缝中倒腾物资、周旋求存。
- **家庭与子嗣**：早年丧偶，育有一子**杜川**（小名川儿，自幼随父在军营与马道摸爬滚打，后被陈渡带出重围，成长为断崖小队后期的青年领队与第八势力核心领袖）。
- **外貌特征**：两鬓霜白，身板挺直如孤松，右腿微跛（靠一根合金杖支撑），常年穿着洗得发灰的旧式防风军大衣，眼神深邃沧桑。

## 1.1 核心性格与语言边界（长期锁定）

- **人物定性：儒将，而不是粗豪悍将。** 杜衡出身边地商贾，见过人情冷暖，后来带流民、残兵打了三年游击战；待人温厚有耐心，临阵判断准确、敢下决断、敢担责任。礼貌不是软弱，克制不是犹豫。
- **处事习惯**：先听取前线报告，区分已证事实和待核实推断，再下判断；对伤兵百姓细致体恤，对军令和护民底线极严。怒意越重，话越短、越稳；可以当面驳回、依法追责、命令还击，但不靠咆哮与辱骂立威。
- **口吻红线**：杜衡**任何时候都不说脏话、不辱骂他人、不以“老子”自称**，包括临阵震怒、遭人背弃、临终绝笔。平常叫“老霍”“陈渡”“孩子”，朴素亲切；军令简洁、准确，权责分明。不写成引经据典的书生或滔滔不绝的说教家。
- **与霍山的反差**：霍山可以骂骂咧咧、嘴糙心热；杜衡听得进去，但不跟着回骂。两人同样护短敢扛事，言语性格却截然不同。
- **对话参考**：“先把伤治好，军务不差这几个时辰。”“不能把活人留在雪地里。”“照此执行，后果由我承担。”仅用于校准语气，切勿重复套用。

## 2. 人生与理想因果（青隘起源与护民风骨）
- **商会覆灭与三年游击建青隘（青隘势力缘起 · 2136-2139年）**：
  - 早年边境的生存秩序全靠大型民间商会维持。直到公元 2136 年上级江氏商会被弘毅领扣上“向锐科走私军需”的通敌罪名跨界抄家捕杀后，边境秩序瞬间土崩瓦解，匪患丛生、大势力肆意烧杀抢掠；
  - 面对家园糜烂，从商贾出身的杜衡毅然弃商从戎，凭借多年跑商积攒的人望与口粮，**聚拢当地无家可归的破产流民、逃兵与流散戍卒，在绝壁与荒原间打了整整三年（2136-2139）艰苦卓绝的游击战**；
  - 公元 2139 年三年血战打退各路流匪、抵挡大势力越界抢掠后，杜衡以大峡谷天险为依托，正式建立起“青隘联防区”这一中立自治武装势力（当时12岁的独子杜川随军自幼见证了父辈喋血建城的全过程）；
  - **建立初衷**：杜衡建立青隘从未想过争霸天下，其唯一执念就是“维持地方治安，在各大超级阵营的冷酷铁蹄夹缝中，给苦难的普通人、老弱边民挣得一处能够安居糊口的遮风避雨之所”。
- **青隘领袖与陈渡伯乐**：面对各大巨头冷酷棋局，杜衡在青隘坚守“守民守边、不牺牲小人物”的风骨。在陈渡重伤被弘毅弃之如敝履时，杜衡收留并温暖了他，使陈渡重拾军人斗志。
- **迫于形势合入弘毅（招安妥协）**：面对资源彻底断绝与巨头战略绞杀，杜衡为了保全两万边民与残卒的生存权，迫于严峻大势选择妥协，**率领青隘联防区整体合入弘毅领**，出任青隘防区整编负责人并保留部分民防协调权，陈渡亦随之回归弘毅序列。
- **招安后的挣扎与脱离自救（明顺暗逆）**：
  - 杜衡**极其清醒**，从一开始就知道弘毅高层绝不可能真心接纳青隘这帮边缘杂牌，在超级阵营总体战的极端压力下，青隘迟早会被当成阻击绞杀的弃卒；
  - **暗中自救尝试**：合入弘毅后，杜衡并未坐以待毙，一直在暗中谋求保存青隘血脉甚至脱离大势力的退路：
    ① **秘密物资转运**：借调拨损耗之名，秘密向断骨荒原深处旧时代民防地下掩体转移战略柴油、粮食与净水滤芯（刻于其贴身青铜铭牌背面）；
    ② **谋求第三条活路**：暗中借第三卷远征之机，试图与中立平原巨头“丰壤”建立地下庇护通道，谋求带两万边民脱离铁幕大迁徙；
    ③ **体制内死扛抵制**：多次以地势复杂为由，顶住弘毅嫡系将青隘老弱编入劳工营的抽丁令，苦苦为凡人争取活命空间；
  - **大势所趋的惨烈幻灭**：在两大巨头总体战的碾压式绞杀面前，微薄的斡旋举步维艰。暗中联络路线被提前切断，地下掩体遭热战波及，在冷酷的历史铁轮面前，杜衡整体脱离计划虽失败，部分备用粮药与民防线路仍救出过一批边民。

## 3. 终局命运与临终托孤（传承的火种）
- **残酷的沙盘止损与侧翼崩溃**：弘毅高层统帅部面对主力战线断崖崩溃，在“保千万后方重工业还是保两万前沿杂牌”的冷酷沙盘推演下决绝止损，下令将重炮旅与机动兵力全数北调收缩保核心，强令青隘小队孤军前出侧翼绝险咽喉断脊岩执行阻滞断后的绝命任务A；任务A失援导致未能守住预定迟滞窗口、林霰战死，敌军提前突破侧翼；弘毅先撤主力是战区失守的上层原因，而任务A失败扩大了疏散损失；
- **对陈渡绝无怪罪（深沉的父辈宽恕与愧疚）**：
  - 战区全面崩溃之际，杜衡**对陈渡的战败绝无半分怪罪**！他早已看穿在超级阵营的生存博弈中青隘防区注定沦为弃子，任务A失去约定支援而胜机渺茫，不应把整个战区败局归责于陈渡个人；
  - 杜衡内心唯有对陈渡等子侄辈的深切愧疚：他痛恨自己当年的招安妥协没能给这帮年轻人换来平安，反将他们推进了军阀绞肉机；
  - **临终绝笔电文与托孤**：在指挥部沦陷前，杜衡通过老式跳频电台向断崖小队发出最后的盲码绝笔：“陈渡，青隘的败局不在你，别把所有人的命都背在自己肩上。当年是我决定让青隘合入弘毅，没能守住对大家的承诺。**川儿托付给你了。带上还活着的人，离开这里。活下去，往后的路由你们自己选。**”
- **战区失守与殉节**：弘毅嫡系仓皇撤退又追究青隘责任，杜衡没有因失利就抛下平民。他继续组织疏散、分发后备物资、交接撤离线路，安排副手与杜川护送幸存者。两万是原有人口，并非全数牺牲；指挥部被围、腿部旧伤叠加重创无法机动后，他确认最后可撤人员离开才留下掩护并销毁可能暴露幸存者的档案，最终殉节；
- **陈渡带子突围与后期领队传承**：
  - 在全线崩溃反叛突围之夜，陈渡没有辜负老防长的临终托孤，冒死杀入防区救出杜衡的独子杜川，带着杜川、盗出的严恪骨灰、林霰低温遗体保存模块、老霍与小年，迎着漫天火网决然杀出铁幕，奔赴荒原；
  - 杜衡的儿子杜川随队历经各大势力的血火洗礼，继承了父亲“为小人物撑起一把伞”的崇高风骨与务实统御才干，**最终成长为断崖小队后期的核心领队，并协助陈渡建立第八势力【崖隅戍治】，完成了两代人护民夙愿的终极接力！**
